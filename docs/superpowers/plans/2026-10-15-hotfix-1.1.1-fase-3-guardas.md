> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar as bibliotecas `hooks/lib/hosts-producao.mjs` e `hooks/lib/sql.mjs` (T8), `hooks/lib/mcp.mjs` e a guarda `hooks/guard-mcp.mjs` (T9), a guarda `hooks/guard-config.mjs` (T10) e a guarda `hooks/guard-subagente.mjs` (T11), cada uma com `avaliar(payload, ctx)` pura e `main` via `rodarGuarda`, testadas por `node --test`.

**Architecture:** As guardas consomem as bibliotecas da fase 1 (`payload`, `config`, `contexto`, `decisao`, `palavras`, `caminhos`) e da fase 2 (`segredos`) só pelas assinaturas do Contrato de interfaces do plano-mestre. `hosts-producao.mjs` e `sql.mjs` guardam paridade literal com as ERE da R3/R2 (o teste lê os `.sh`). `guard-mcp` decide MCP/WebFetch por gatilho (servidor, identificador, campo de conexão) × classe da ferramenta; `guard-config` decide escrita em configuração de guarda por ferramenta de arquivo e por candidato de caminho em posição de destino; `guard-subagente` é lista branca para S e sai sem `git` nem config para O (`rodarGuarda(avaliar, { leve: true })`). Registro em `hooks.json` e `runAll` ficam para T12 (fase 4).

**Tech Stack:** Node `>=22.18` (ESM, `node --test`, `node:assert/strict`, `node:fs|path|os|child_process|url`), bash 3.2 só no teste de paridade (`grep -E`), zero dependências npm.

### Premissas sobre o contrato de T1–T3 (conferir no plano da fase 1 antes de T8; divergência ⇒ o orquestrador decide e registra no ledger)

1. `Segmento.conector` = operador que **segue** o segmento (`&&`, `||`, `;`, `|`, `&`, `\n`), `null` no último.
2. `rodarNode(guarda, …)` recebe o **nome do arquivo** em `hooks/` (`'guard-mcp.mjs'`).
3. `fixtureRepo({})` devolve o caminho (string); `fixtureRepo({ worktree: true, nomeWT: 'wt-teste' })` devolve `{ principal, wt }` (opção `nomeWT` de A10 da fase 1). Esta fase sempre passa `nomeWT: 'wt-teste'`: o padrão `agent-teste` cai sob `*/.claude/worktrees/agent-*` e, com M-B = não (hipótese conservadora de `MEDICOES`), O nesse `cwd` vira S pelo fallback de REQ-H0-3 — os testes de O no worktree passariam a medir S. S nos testes vem sempre de `agent_id`. Esta fase escreve `harness.config.json` e arquivos à mão (`escrever`), sem depender das opções `config`/`files`.
4. `Candidato.palavra` é a mesma referência de `seg.palavras[k]`.
5. `contextoLeve(payload)` devolve só `{ s, sPeloCwd }` (sem `config`); `guard-subagente.avaliar` completa com `montarContexto` quando `ctx.config` falta.
6. `Contexto.env` é o `env` passado a `montarContexto`; `Contexto.home` = `env.HOME`.
7. `candidatos(seg, ctx)` marca `destino: true` exatamente nas posições de REQ-H4-3 e REQ-H0-10 (v) (via `posicaoDeDestino`). Caso de destino que falhe em T10 é defeito de T3 — reabra T3, não contorne em `guard-config`.
8. `ehAlvoConfig(abs, ctx, { diretorios = false } = {})` (A8 da fase 1, `caminhos.mjs`) é a **fonte única** de REQ-H4-1: compara as formas lexical e física (realpath do ancestral existente) de `abs` contra as das raízes e de `~/.claude`; `diretorios: true` acrescenta os diretórios-alvo (só REQ-H4-3). `guard-config` não reimplementa a lista.
9. `lerConfig` (A11 da fase 1, `config.mjs`) já descarta de `subagente.env` todo nome fora de `RE_NOME_ENV_SUBAGENTE`, com aviso: `guard-subagente` confia em `ctx.config.subagente.env` e **não** reaplica a forma (fonte única; MH82 muta `lerConfig`).
10. `anotarDiretorios(analise, ctx)` anota recursivamente as análises aninhadas (substituição, `bash -c`, heredoc, alvo de redirecionamento) com os diretórios herdados do segmento; quem varre análises aninhadas chama a função **uma vez**, na análise raiz.
11. `envLimpo(extra)` vem de `test/helpers.mjs` (A10 da fase 1). Nenhum teste desta fase o redefine.
12. `Segmento.controle:boolean` existe desde a T2; o acréscimo coordenado `Segmento.palavrasControle:string[]` (fase 1, consumido pela T7) não é usado aqui — REQ-H7-2 só precisa saber **se** há palavra de controle.

## Review Focus

Entradas que a spec implica e que nenhuma linha de §6 exercita, mais prováveis de morder quem usa (o teste de cada uma está na task dona):

1. **Latência do orquestrador em `guard-subagente`** (Review Focus 1 do plano-mestre). Matcher `.*` roda em toda ferramenta; O sai sem `git` e sem config, mediana < 150 ms em 5 execuções — ou, em máquina lenta, mediana do hook menos a mediana de `node -e ''` (5 execuções) < 100 ms. Teste em T11 (`spawnSync` cronometrado + `git` falso no `PATH` que marca chamada).
2. **`tool_input` de MCP grande ou profundo.** Objeto com 2.000 níveis e array de 100.000 strings: `gatilhoProducao` percorre sem recursão de pilha, acha a URL de prod lá no fundo e decide em < 1 s. Teste em T9.
3. **SQL enorme ou malformado.** `select` com 200 KB, comentário `/*` aberto de 200 KB, literal com 100.000 `''`: `classificarSql` termina em < 1 s; o que não fecha vira escrita. Teste em T8.
4. **Host de produção em maiúsculas** (`https://API.PROD.EXAMPLE.COM`). O bash da R3 deixa passar (o `sed` do filtro de extensão é sem `-i`); `casaProducao` conta. Divergência declarada, mais restritiva. Teste em T8.
5. **`path` de `Grep`/`Glob` que é a raiz escrita de outro jeito** (`<raiz>/`, `<raiz>/.`, `.`, `./` com `cwd` na raiz). S nega como "path = raiz". Teste em T11.

const CLASSES_POSIX = Object.freeze({
  space: ' \\t\\n\\r\\f\\v',
  blank: ' \\t',
  digit: '0-9',
  alpha: 'A-Za-z',
  alnum: 'A-Za-z0-9',
  upper: 'A-Z',
  lower: 'a-z',
  xdigit: '0-9A-Fa-f',
  punct: '!-\\/:-@\\[-`{-~',

/** ERE POSIX → fonte de RegExp JS. Dentro de colchete, `\` é literal (POSIX) e classes [:x:] são expandidas. */
export function ereParaRegExp(ere) {
  let out = '';
  let i = 0;
  while (i < ere.length) {
    const c = ere[i];
    if (c === '\\') {
      out += ere.slice(i, i + 2);
      i += 2;
      continue;
    }
    if (c !== '[') {
      out += c;
      i += 1;
      continue;
    }
    let j = i + 1;
    let corpo = '';
    if (ere[j] === '^') {
      corpo += '^';
      j += 1;
    }
    if (ere[j] === ']') {
      corpo += '\\]';
      j += 1;
    }
    while (j < ere.length && ere[j] !== ']') {
      if (ere.startsWith('[:', j)) {
        const fim = ere.indexOf(':]', j + 2);
        if (fim < 0) throw new SyntaxError(`classe POSIX sem fechamento em ${ere}`);
        const nome = ere.slice(j + 2, fim);
        if (!Object.hasOwn(CLASSES_POSIX, nome)) throw new SyntaxError(`classe POSIX desconhecida [:${nome}:]`);
        corpo += CLASSES_POSIX[nome];
        j = fim + 2;
        continue;
      }
      const d = ere[j];
      corpo += d === '\\' || d === '[' ? `\\${d}` : d;
      j += 1;
    }
    if (j >= ere.length) throw new SyntaxError(`colchete sem fechamento em ${ere}`);
    out += `[${corpo}]`;
    i = j + 1;
  }
  return out;
}

export const ERE_HOST_PRODUCAO = new RegExp(ereParaRegExp(HOST_ERE), 'i');
export const ERE_URL_PRODUCAO = new RegExp(ereParaRegExp(URLSEG_ERE), 'i');

const EXTENSOES = new Set(EXT_ARQUIVO.split('|'));
const RE_HOST_GLOBAL = new RegExp(ERE_HOST_PRODUCAO.source, 'gi');

/** Host de produção com o filtro de R3: casamento cujo último rótulo é extensão de arquivo não conta. */
export function hostDeProducao(valor) {
  for (const m of String(valor).matchAll(RE_HOST_GLOBAL)) {
    const sufixo = m[0].toLowerCase().replace(/[^a-z0-9.-]+$/, '');
    const ultimo = sufixo.slice(sufixo.lastIndexOf('.') + 1);
    if (ultimo !== '' && !EXTENSOES.has(ultimo)) return true;
  }
  return false;
}

function testarEre(ere, linha) {
  try {
    return new RegExp(ereParaRegExp(ere), 'i').test(linha);
  } catch {
    return false;
  }
}

/** REQ-H2-1 (c): o valor casa host/URL de produção da R3 (ou GABARITO_PROD_PATTERNS, que substitui) ou _EXTRA. */
export function casaProducao(valor, env = process.env) {
  if (typeof valor !== 'string' || valor === '') return false;
  const substituto = env.GABARITO_PROD_PATTERNS;
  const extra = env.GABARITO_PROD_PATTERNS_EXTRA;
  for (const linha of valor.split('\n')) {
    if (substituto) {
      if (testarEre(substituto, linha)) return true;
    } else if (hostDeProducao(linha) || ERE_URL_PRODUCAO.test(linha)) {
      return true;
    }
    if (extra && testarEre(extra, linha)) return true;
  }
  return false;
}

export function sqlDestrutivo(sql) {
  return typeof sql === 'string' && RE_PAYLOAD_DESTRUTIVO.test(sql);

export class SqlIlegivel extends Error {}

const LEITURA_INICIAL = new Set(['select', 'with', 'explain', 'show', 'values', 'table']);
const ESCRITA = new Set([
  'insert', 'update', 'delete', 'merge', 'upsert', 'truncate', 'drop', 'alter', 'create', 'grant', 'revoke',
  'vacuum', 'refresh', 'cluster', 'reindex', 'reset', 'import', 'attach', 'detach', 'pragma',
]);
const OPCOES_EXPLAIN = new Set([
  'analyze', 'analyse', 'verbose', 'costs', 'buffers', 'settings', 'wal', 'timing', 'summary', 'generic_plan',
  'memory', 'serialize', 'format', 'text', 'xml', 'json', 'yaml', 'true', 'false', 'on', 'off',
]);
const RE_DOLAR = /\$([A-Za-z_][A-Za-z0-9_]*)?\$/y;

function fimLiteral(sql, i, barraEscapa) {
  while (i < sql.length) {
    const c = sql[i];
    if (barraEscapa && c === '\\') {
      i += 2;
      continue;
    }
    if (c === "'") {
      if (sql[i + 1] === "'") {
        i += 2;
        continue;
      }
      return i + 1;
    }
    i += 1;
  }
  throw new SqlIlegivel('literal sem fechamento');
}

function fimAspasDuplas(sql, i) {
  while (i < sql.length) {
    if (sql[i] === '"') {
      if (sql[i + 1] === '"') {
        i += 2;
        continue;
      }
      return i + 1;
    }
    i += 1;
  }
  throw new SqlIlegivel('identificador entre aspas sem fechamento');
}

function fimComentario(sql, i) {
  let prof = 0;
  while (i < sql.length) {
    if (sql.startsWith('/*', i)) {
      prof += 1;
      i += 2;
    } else if (sql.startsWith('*/', i)) {
      prof -= 1;
      i += 2;
      if (prof === 0) return i;
    } else {
      i += 1;
    }
  }
  throw new SqlIlegivel('comentário sem fechamento');
}

/** '…' com '', E'…' com \, "…", $tag$…$tag$, -- e /* *\/ aninhado. Sem fechamento ⇒ SqlIlegivel. */
export function tokensSql(sql) {
  const toks = [];
  const n = sql.length;
  let i = 0;
  while (i < n) {
    const c = sql[i];
    if (c === ' ' || c === '\t' || c === '\n' || c === '\r' || c === '\f' || c === '\v') {
      i += 1;
    } else if (c === '-' && sql[i + 1] === '-') {
      const f = sql.indexOf('\n', i);
      i = f < 0 ? n : f + 1;
    } else if (c === '/' && sql[i + 1] === '*') {
      i = fimComentario(sql, i);
    } else if (c === "'") {
      i = fimLiteral(sql, i + 1, false);
      toks.push({ t: 'literal', v: '' });
    } else if (c === '"') {
      const f = fimAspasDuplas(sql, i + 1);
      toks.push({ t: 'ident', v: sql.slice(i + 1, f - 1) });
      i = f;
    } else if (c === '$') {
      RE_DOLAR.lastIndex = i;
      const m = RE_DOLAR.exec(sql);
      if (m) {
        const f = sql.indexOf(m[0], i + m[0].length);
        if (f < 0) throw new SqlIlegivel('dollar-quote sem fechamento');
        toks.push({ t: 'dolar', v: '' });
        i = f + m[0].length;
      } else {
        let j = i + 1;
        while (j < n && sql[j] >= '0' && sql[j] <= '9') j += 1;
        toks.push({ t: 'simbolo', v: sql.slice(i, j) });
        i = j;
      }
    } else if (/[A-Za-z_]/.test(c)) {
      let j = i + 1;
      while (j < n && /[A-Za-z0-9_$]/.test(sql[j])) j += 1;
      const w = sql.slice(i, j);
      if ((w === 'e' || w === 'E') && sql[j] === "'") {
        i = fimLiteral(sql, j + 1, true);
        toks.push({ t: 'literal', v: '' });
      } else {
        toks.push({ t: 'palavra', v: w.toLowerCase() });
        i = j;
      }
    } else if (c >= '0' && c <= '9') {
      let j = i + 1;
      while (j < n && /[0-9.eE]/.test(sql[j])) j += 1;
      toks.push({ t: 'num', v: sql.slice(i, j) });
      i = j;
    } else {
      toks.push({ t: 'simbolo', v: c });
      i += 1;
    }
  }
  return toks;
}

const ehPalavra = (t, v) => t !== undefined && t.t === 'palavra' && t.v === v;
const ehSimbolo = (t, v) => t !== undefined && t.t === 'simbolo' && t.v === v;

function depoisDoExplain(toks, i) {
  if (ehSimbolo(toks[i], '(')) {
    let prof = 0;
    for (let j = i; j < toks.length; j += 1) {
      if (ehSimbolo(toks[j], '(')) prof += 1;
      else if (ehSimbolo(toks[j], ')')) {
        prof -= 1;
        if (prof === 0) return j + 1;
      }
    }
    return toks.length;
  }
  while (toks[i] !== undefined && toks[i].t === 'palavra' && OPCOES_EXPLAIN.has(toks[i].v)) i += 1;
  return i;
}

/** Posições de comando: 1º token; token após qualquer `(`; token após `)` que volta ao nível 0; alvo de EXPLAIN. */
function posicoesDeComando(toks) {
  const pos = new Set([0]);
  let prof = 0;
  for (let i = 0; i < toks.length; i += 1) {
    if (ehSimbolo(toks[i], '(')) {
      prof += 1;
      pos.add(i + 1);
    } else if (ehSimbolo(toks[i], ')')) {
      prof -= 1;
      if (prof === 0) pos.add(i + 1);
    }
  }
  for (const i of [...pos]) if (ehPalavra(toks[i], 'explain')) pos.add(depoisDoExplain(toks, i + 1));
  return [...pos].filter((i) => i < toks.length);
}

function escritaEm(toks, i) {
  const t = toks[i];
  if (t === undefined || t.t !== 'palavra') return false;
  const prox = toks[i + 1];
  if (ESCRITA.has(t.v)) return true;
  if (t.v === 'comment' && ehPalavra(prox, 'on')) return true;
  if (t.v === 'set' && prox !== undefined && (prox.t === 'palavra' || prox.t === 'ident')
    && (ehPalavra(toks[i + 2], 'to') || ehSimbolo(toks[i + 2], '='))) return true;
  if (t.v === 'copy' && toks.slice(i + 1).some((x) => ehPalavra(x, 'from') || ehPalavra(x, 'to'))) return true;
  if (t.v === 'lock' && ehPalavra(prox, 'table')) return true;
  if (t.v === 'do' && prox !== undefined && (prox.t === 'dolar' || prox.t === 'literal')) return true;
  if (t.v === 'call' && toks.slice(i + 1, i + 6).some((x) => ehSimbolo(x, '('))) return true;
  if (t.v === 'load' && prox !== undefined && prox.t === 'literal') return true;
  return false;
}

/** REQ-H2-3: 'leitura' só com 1º token de leitura, sem `into` e sem escrita em posição de comando. */
export function classificarSql(sql) {
  if (typeof sql !== 'string') return 'escrita';
  let toks;
  try {
    toks = tokensSql(sql);
  } catch (e) {
    if (e instanceof SqlIlegivel) return 'escrita';
    throw e;
  }
  const pv = toks.findIndex((t) => ehSimbolo(t, ';'));
  if (pv >= 0) {
    if (pv < toks.length - 1) return 'escrita'; // mais de um statement
    toks = toks.slice(0, pv); // `;` final sozinho
  }
  if (toks.length === 0 || toks[0].t !== 'palavra' || !LEITURA_INICIAL.has(toks[0].v)) return 'escrita';
  if (toks.some((t) => ehPalavra(t, 'into'))) return 'escrita';
  for (const i of posicoesDeComando(toks)) if (escritaEm(toks, i)) return 'escrita';
  return 'leitura';
}

/**
 * MCP: servidor, nome, classe (REQ-H2-3) e gatilhos de produção (REQ-H2-1) e de segredo (REQ-H2-2).
 */
import { casaProducao } from './hosts-producao.mjs';

const RE_MCP = /^mcp__(.+?)__(.*)$/s;

export function servidorDe(toolName) {
  const m = RE_MCP.exec(typeof toolName === 'string' ? toolName : '');
  return m ? m[1] : null;
}

export function nomeFerramenta(toolName) {
  const t = typeof toolName === 'string' ? toolName : '';
  const m = RE_MCP.exec(t);
  if (m) return m[2];
  return t.startsWith('mcp__') ? '' : t;
}

export function tokensNome(nome) {
  return String(nome)
    .replace(/([a-z0-9])([A-Z])/g, '$1 $2')
    .replace(/([A-Z]+)([A-Z][a-z])/g, '$1 $2')
    .split(/[^A-Za-z0-9]+/)
    .filter(Boolean)
    .map((t) => t.toLowerCase());
}

const ESCRITA_MCP = new Set((
  'create update delete set add remove apply deploy put patch move send upload rerequest restore reset merge run spawn '
  + 'execute stage promote rollback invalidate install issue buy assign approve resolve reply respond register trash save '
  + 'start stop cancel kill generate import publish edit copy duplicate share revoke activate pause extend record comment '
  + 'mark label unlabel forward archive rename write post sync transfer verify accept complete'
).split(' '));
const LEITURA_MCP = new Set((
  'get list search read query find fetch count aggregate describe filter analyze export download check status preview '
  + 'lookup whoami health navigate open view load browse screenshot snapshot'
).split(' '));
const GERA_LEITURA = new Set(['types', 'typescript', 'schema']);

/** REQ-H2-3: escrita prevalece; generate+types|typescript|schema é leitura; execute+sql é classe própria. */
export function classeFerramenta(nome) {
  const toks = tokensNome(nome);
  if (toks.includes('execute') && toks.includes('sql')) return 'execute_sql';
  const geraLeitura = toks.some((t) => GERA_LEITURA.has(t));
  if (toks.some((t) => ESCRITA_MCP.has(t) && !(t === 'generate' && geraLeitura))) return 'escrita';
  if (geraLeitura && toks.includes('generate')) return 'leitura'; // exceção nominal: nenhum token de LEITURA_MCP no nome
  if (toks.some((t) => LEITURA_MCP.has(t))) return 'leitura';
  return 'desconhecida';
}

const CONEXAO = new Set(
  'url uri host hostname endpoint project projectid ref dsn conn connection database db command domain'.split(' '),
);

function ehChaveDeConexao(chave, sqlNoNome) {
  return tokensNome(chave).some((t) => CONEXAO.has(t) || (sqlNoNome && (t === 'query' || t === 'sql')));
}

/** Toda string sob `valor` (o próprio valor, arrays e objetos aninhados), sem recursão de pilha. */
function* stringsSob(valor) {
  const pilha = [valor];
  while (pilha.length > 0) {
    const v = pilha.pop();
    if (typeof v === 'string') yield v;
    else if (Array.isArray(v)) for (const x of v) pilha.push(x);
    else if (v !== null && typeof v === 'object') for (const x of Object.values(v)) pilha.push(x);
  }
}

/** Valores de campos de conexão em qualquer nível do tool_input, sem recursão de pilha. */
function* valoresDeConexao(raiz, sqlNoNome) {
  const pilha = [raiz];
  while (pilha.length > 0) {
    const no = pilha.pop();
    if (Array.isArray(no)) {
      for (const x of no) if (x !== null && typeof x === 'object') pilha.push(x);
      continue;
    }
    if (no === null || typeof no !== 'object') continue;
    for (const [k, v] of Object.entries(no)) {
      if (ehChaveDeConexao(k, sqlNoNome)) yield* stringsSob(v);
      else if (v !== null && typeof v === 'object') pilha.push(v);
    }
  }
}

/** REQ-H2-1: 'a' servidor listado · 'b' identificador no tool_input serializado · 'c' campo de conexão casa prod. */
export function gatilhoProducao(payload, ctx) {
  const prod = ctx.config.producao;
  const srv = servidorDe(payload.toolName);
  if (srv !== null && prod.servidores.includes(srv)) return 'a';
  const serial = JSON.stringify(payload.toolInput ?? {}).toLowerCase();
  if (prod.identificadores.some((id) => typeof id === 'string' && id !== '' && serial.includes(id.toLowerCase()))) return 'b';
  if (payload.toolName === 'WebFetch') return casaProducao(payload.url ?? '', ctx.env) ? 'c' : null;
  const sqlNoNome = tokensNome(nomeFerramenta(payload.toolName)).some((t) => t === 'sql' || t === 'execute');
  for (const v of valoresDeConexao(payload.toolInput, sqlNoNome)) if (casaProducao(v, ctx.env)) return 'c';
  return null;
}

/** REQ-H2-2. */
export function gatilhoSegredo(nome) {
  const n = String(nome).toLowerCase();
  return n === 'get_edge_function' || /env|secret|token|credential|key/.test(n);
}

/**
 * gabarito-mestre · guard-mcp.mjs — REQ-H2-1..H2-5 (MCP e WebFetch em produção).
 * Matcher (T12): mcp__.*|WebFetch. `avaliar` é pura; o main escreve os avisos de REQ-H2-5 em stderr.

import { realpathSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { allow, deny, askOuDeny, rodarGuarda } from './lib/decisao.mjs';
import { servidorDe, nomeFerramenta, classeFerramenta, gatilhoProducao, gatilhoSegredo } from './lib/mcp.mjs';
import { classificarSql, sqlDestrutivo } from './lib/sql.mjs';

export const AVISO_PRODUCAO_AUSENTE = 'producao.* ausente — prod só detectada por padrão de host';

function textoSql(toolInput) {
  for (const k of ['query', 'sql']) if (typeof toolInput?.[k] === 'string') return toolInput[k];
  return '';
}

function rotulo(payload) {
  return payload.toolName === 'WebFetch' ? 'WebFetch' : `MCP ${servidorDe(payload.toolName) ?? '?'}`;
}

export function avaliar(payload, ctx) {
  const ehWeb = payload.toolName === 'WebFetch';
  const ehMcp = payload.toolName.startsWith('mcp__');
  if (!ehWeb && !ehMcp) return allow();
  const nome = ehWeb ? 'WebFetch' : nomeFerramenta(payload.toolName);
  const classe = ehWeb ? 'leitura' : classeFerramenta(nome);
  const medida = ehWeb ? 'WebFetch' : 'mcp';
  const g = gatilhoProducao(payload, ctx);

  if (g !== null) {
    if (ctx.s) return deny(`${rotulo(payload)} em produção (gatilho ${g}) é do orquestrador (REQ-H2-4)`, 'H2-4');
    if (classe === 'execute_sql') {
      return classificarSql(textoSql(payload.toolInput)) === 'leitura'
        ? askOuDeny(payload, medida, `execute_sql de leitura em produção (gatilho ${g}): aprovar = autorizar o SQL exibido; função chamada por \`SELECT\` pode escrever (REQ-H2-4)`, 'H2-4')
        : deny(`execute_sql que escreve em produção (gatilho ${g}) é proibido pela R3, sem escape hatch (REQ-H2-4)`, 'H2-4');
    }
    if (classe === 'leitura') {
      return askOuDeny(payload, medida, `Leitura em produção via ${rotulo(payload)} (gatilho ${g}): peça autorização nominal ao usuário (R3, REQ-H2-4)`, 'H2-4');
    }
    return deny(`Escrita em produção via ${rotulo(payload)} (${nome}: ${classe}, gatilho ${g}) é proibida pela R3, sem escape hatch (REQ-H2-4)`, 'H2-4');
  }

  if (ehMcp && gatilhoSegredo(nome)) {
    if (ctx.s) return deny(`ferramenta MCP que pode exibir segredo (${nome}) é do orquestrador (REQ-H2-2)`, 'H2-2');
    return askOuDeny(payload, medida, `ferramenta MCP que pode exibir segredo (${nome}): aprove só se o valor não for exibido (REQ-H2-2)`, 'H2-2');
  }

  if (!ctx.s && classe === 'execute_sql' && sqlDestrutivo(textoSql(payload.toolInput))) {
    return deny('execute_sql destrutivo (DROP/TRUNCATE/DELETE FROM) bloqueado pela R2 em qualquer ambiente, sem escape hatch (REQ-H2-4)', 'H2-4');
  }
  return allow(); // S sem gatilho: REQ-H7-5 em guard-subagente
}

/** REQ-H2-5: aviso a cada chamada MCP de O quando faltam as duas chaves producao.*. */
export function avisos(payload, ctx) {
  return payload.toolName.startsWith('mcp__') && !ctx.s && ctx.config.producaoAusente ? [AVISO_PRODUCAO_AUSENTE] : [];
}

const ehMain = (() => {
  try {
    return realpathSync(process.argv[1] ?? '') === realpathSync(fileURLToPath(import.meta.url));
  } catch {
    return false;
  }
})();
if (ehMain) {
  await rodarGuarda((payload, ctx) => {
    for (const a of avisos(payload, ctx)) process.stderr.write(`gabarito-mestre: ${a}\n`);
    return avaliar(payload, ctx);
  });
}

  for (const seg of analise.segmentos) {
    for (const p of [...seg.palavras, ...seg.atribuicoes.map((a) => a.valor), ...seg.redirs.map((r) => r.alvo).filter(Boolean)]) {
      for (const x of p.internos ?? []) yield* analisesDe(x);
    }
    for (const x of seg.internos ?? []) yield* analisesDe(x);
    for (const h of seg.heredocs) if (h.corpoAnalise) yield* analisesDe(h.corpoAnalise);
  }
}

function primeiroNaoOpcao(ws) {
  return ws.find((w) => !w.startsWith('-')) ?? '';
}

function ehOnboardingConfig(ws) {
  const b = basename(ws[0]);
  if (b === 'onboarding-config.mjs') return true;
  return (b === 'node' || b === 'nodejs') && basename(primeiroNaoOpcao(ws.slice(1))) === 'onboarding-config.mjs';
}

/** Argumentos depois de `claude` (direto ou via npx|bunx|pnpm dlx|yarn dlx); null se não é claude. */
function argsDoClaude(ws) {
  const b = basename(ws[0]);
  if (CLAUDE.has(ws[0]) || b === 'claude') return ws.slice(1);
  let i = -1;
  if (b === 'npx' || b === 'bunx') i = 1;
  else if ((b === 'pnpm' || b === 'yarn') && ws[1] === 'dlx') i = 2;
  if (i < 0) return null;
  while (i < ws.length && ws[i].startsWith('-')) i += 1;
  const pacote = (ws[i] ?? '').replace(/@[^/@]*$/, '');
  return CLAUDE.has(pacote) ? ws.slice(i + 1) : null;
}

/** REQ-H4-4. O subcomando `plugin|config|mcp` é procurado entre as palavras ANTES de `--` (opção global com valor
 *  pode vir antes: `claude --model x mcp add y`); o que vem depois de `--` é do servidor MCP (`… -- node s.mjs --help`).
 *  `--version`/`--help` só são leitura sem subcomando — sem subcomando e sem `-p`, nada escreve. */
function claudeEscreve(args) {
  const fim = args.indexOf('--');
  const antes = fim >= 0 ? args.slice(0, fim) : args;
  const k = antes.findIndex((a) => a === 'plugin' || a === 'config' || a === 'mcp');
  if (k >= 0) {
    const sub = antes[k];
    const acao = antes.slice(k + 1).find((a) => !a.startsWith('-'));
    if ((sub === 'mcp' || sub === 'plugin') && acao === 'list') return false;
    if (sub === 'config' && (acao === 'get' || acao === 'list')) return false;
    return true;
  }
  return antes.some((a) => a === '-p' || a === '--print' || a.startsWith('--print='));
}

/** REQ-H4-4. */
function semCaminho(seg, payload, ctx) {
  if (seg.comandoEfetivo === null) return null; // r24 E9: decide pelo comando efetivo (wrappers desembrulhados na T2)
  const ws = seg.palavras.slice(seg.idxEfetivo).map((p) => p.valor);
  if (ehOnboardingConfig(ws)) {
    if (ws.includes('--dry-run')) return null;
    if (ctx.s) return deny('onboarding-config.mjs grava harness.config.json/settings: subagente não edita configuração de guarda (REQ-H4-4)', 'H4-4');
    return MEDICOES.askChegaEmAuto.Bash
      ? ask('onboarding-config.mjs grava configuração de guarda: confirme com o usuário (REQ-H4-4)', 'H4-4')
      : allow();
  }
  const args = argsDoClaude(ws);
  if (args !== null && claudeEscreve(args)) {
    const fim = args.indexOf('--');
    const sub = ['plugin', 'config', 'mcp'].find((s) => (fim >= 0 ? args.slice(0, fim) : args).includes(s)) ?? '-p'; // nunca ecoa o prompt
    return decidir(payload, ctx, 'Bash', `\`claude ${sub}\` altera plugin/config/MCP ou roda sessão não interativa`, 'H4-4');
  }
  return null;
}

/** REQ-H4-3: só candidato em posição de destino. `abs === null` tem duas origens:
 *  - a própria palavra tem variável fora da lista de REQ-H0-4 ou `~user` (marca expansao/til): limite declarado para O
 *    (§5; spec l.53) — não conta; S já é negado por H7-2 (marca expansao/til);
 *  - diretório corrente desconhecido (`cd -`, `cd $X`) com destino relativo: conta (REQ-H0-8, l.57) ⇒ O ask, S deny. */
function destinos(seg, payload, ctx) {
  for (const cand of candidatos(seg, ctx)) {
    if (!cand.destino) continue;
    for (const abs of cand.abs) {
      if (abs === null) {
        if (cand.palavra.marcas.expansao || cand.palavra.marcas.til) continue;
        return decidir(payload, ctx, 'Bash', `destino \`${cand.valor}\` com diretório corrente desconhecido (cd - ou cd com variável)`, 'H4-3');
      }
      if (ehAlvoConfig(abs, ctx, { diretorios: true })) return decidir(payload, ctx, 'Bash', `escrita em configuração de guarda (${abs})`, 'H4-3');
    }
  }
  return null;
}

function avaliarComando(payload, ctx) {
  const cmd = payload.command;
  if (typeof cmd !== 'string' || cmd.trim() === '') return deny('comando ausente ou ilegível (REQ-H0-2)', 'H0-2');
  let analise;
  try {
    analise = tokenizar(cmd);
  } catch (e) {
    if (e instanceof ErroIlegivel) return deny(`comando ilegível: ${e.message} (REQ-H0-2)`, 'H0-2');
    throw e;
  }
  anotarDiretorios(analise, ctx); // uma vez: as análises aninhadas herdam seg.dirs (premissa 10)
  const decisoes = [allow()];
  for (const a of analisesDe(analise)) {
    for (const seg of a.segmentos) {
      if (seg.wrapperIlegivel) {
        decisoes.push(deny(`wrapper \`${seg.comando}\` com opção não reconhecida: comando efetivo ilegível (REQ-H0-2, r24 E9)`, 'H0-2'));
        continue;
      }
      const d = semCaminho(seg, payload, ctx) ?? destinos(seg, payload, ctx);
      if (d !== null) decisoes.push(d);
    }
  }
  return compor(decisoes);
}

export function avaliar(payload, ctx) {
  const t = payload.toolName;
  if (FERRAMENTAS_DE_ARQUIVO.has(t)) {
    const bruto = t === 'NotebookEdit' ? (payload.notebookPath ?? payload.filePath) : payload.filePath;
    if (typeof bruto !== 'string' || bruto === '') return allow(); // sem caminho: a própria ferramenta recusa
    const abs = normalizar(bruto, ctx.cwd, ctx);
    if (abs !== null && ehAlvoConfig(abs, ctx)) return decidir(payload, ctx, t, `${t} em configuração de guarda (${abs})`, 'H4-2');
    return allow();
  }
  if (t === 'Bash' || t === 'Monitor') return avaliarComando(payload, ctx);
  return allow();
}

const ehInterpretador = (b) => INTERPRETADORES.has(b) || /^python3\.\d+$/.test(b);
const valores = (seg) => seg.palavras.slice(seg.idxComando).map((p) => p.valor);

function existe(abs) {
  try {
    statSync(abs);
    return true;
  } catch {
    return false;
  }
}
function ehArquivoRegular(abs) {
  try {
    return statSync(abs).isFile();
  } catch {
    return false;
  }
}

/** deny de S. "tratado como subagente pelo cwd" (REQ-H0-3) e o sufixo de REQ-H1-2 são acrescentados por `emitir`. */
const negar = (motivo, regra) => deny(motivo, regra);

// ───────────────────────── H7-1 ferramentas de arquivo ─────────────────────────

function leitura(bruto, c, ferramenta) {
  if (typeof bruto !== 'string' || bruto === '') return negar(`${ferramenta} sem caminho (REQ-H7-1)`, 'H7-1');
  const abs = normalizar(bruto, c.cwd, c);
  if (abs === null) return negar(`${ferramenta} com caminho não resolvido (REQ-H7-1)`, 'H7-1');
  return noEscopoLeitura(abs, c) ? allow() : negar(`${ferramenta} fora do escopo de leitura do subagente: ${abs} (REQ-H7-1)`, 'H7-1');
}

function escrita(bruto, c, ferramenta) {
  if (typeof bruto !== 'string' || bruto === '') return negar(`${ferramenta} sem caminho (REQ-H7-1)`, 'H7-1');
  const abs = normalizar(bruto, c.cwd, c);
  if (abs === null) return negar(`${ferramenta} com caminho não resolvido (REQ-H7-1)`, 'H7-1');
  return noEscopoEscrita(abs, c)
    ? allow()
    : negar(`${ferramenta} fora do escopo de escrita do subagente (só o próprio worktree e o tmp): ${abs} (REQ-H7-1)`, 'H7-1');
}

function busca(payload, c) {
  const t = payload.toolName;
  const bruto = payload.path;
  if (typeof bruto !== 'string' || bruto === '') return negar(`${t} sem path: passe um subdiretório nomeado (REQ-H7-1)`, 'H7-1');
  const abs = normalizar(bruto, c.cwd, c);
  if (abs === null) return negar(`${t} com path não resolvido (REQ-H7-1)`, 'H7-1');
  if (raizesDe(c).has(semBarra(abs))) return negar(`${t} com path na raiz do repositório: passe um subdiretório nomeado (REQ-H7-1)`, 'H7-1');
  return noEscopoLeitura(abs, c) ? allow() : negar(`${t} fora do escopo de leitura do subagente: ${abs} (REQ-H7-1)`, 'H7-1');
}

// ───────────────────────── H7-5 MCP ─────────────────────────

function avaliarMcp(payload, c) {
  const srv = servidorDe(payload.toolName);
  const nome = nomeFerramenta(payload.toolName);
  if (srv === null || !c.config.subagente.mcpServidores.includes(srv)) {
    return negar(`MCP do servidor ${srv ?? '?'} fora de subagente.mcp.servidores (REQ-H7-5)`, 'H7-5');
  }
  const classe = classeFerramenta(nome);
  if (classe !== 'leitura') return negar(`MCP ${nome} (${classe}): subagente só faz leitura (REQ-H7-5)`, 'H7-5');
  if (gatilhoProducao(payload, c) !== null || gatilhoSegredo(nome)) {
    return negar(`MCP ${nome} com gatilho de produção ou de segredo é do orquestrador (REQ-H7-5)`, 'H7-5');
  }
  return allow();
}

// ───────────────────────── H7-2 estrutura ─────────────────────────

function palavrasDe(seg) {
  return [...seg.palavras, ...seg.atribuicoes.map((a) => a.valor), ...seg.redirs.map((r) => r.alvo).filter(Boolean)];
}

function heredocEscreveArquivo(seg) {
  const b = basename(seg.comando ?? '');
  if (b === 'cat') {
    return seg.redirs.some((r) => r.direcao === 'saida' && r.alvo !== null && (r.fd === null || r.fd === 1)
      && (r.op === '>' || r.op === '>>' || r.op === '>|'));
  }
  if (b === 'tee') return seg.palavras.slice(seg.idxComando + 1).some((p) => !p.valor.startsWith('-'));
  return false;
}

/** REQ-H7-2. `c.config.subagente.env` já vem filtrado pela forma de nome (lerConfig, A11 da fase 1 — fonte única). */
function atribuicaoInvalida(nome, valor, c) {
  const sempre = ATRIBUICOES_SEMPRE.includes(nome);
  const configurada = c.config.subagente.env.includes(nome);
  if (!sempre && !configurada) {
    return `atribuição ${nome}=… fora de CI|NODE_ENV|FORCE_COLOR|NO_COLOR|TZ|LANG|LC_ALL e de subagente.env (REQ-H7-2)`;
  }
  const ok = nome === 'TZ' ? RE_VALOR_TZ.test(valor) && !valor.includes('..') : RE_VALOR_ENV.test(valor);
  return ok ? null : `valor de ${nome} fora da forma permitida (sem /, sem espaço) (REQ-H7-2)`;
}

/** Índice do interpretador efetivo: o próprio comando ou o pacote depois de npx|bunx|pnpm exec|pnpm dlx|yarn dlx. */
function idxInterpretador(ws) {
  const b = basename(ws[0]);
  let i = 0;
  if (b === 'npx' || b === 'bunx') i = 1;
  else if (b === 'pnpm' && (ws[1] === 'exec' || ws[1] === 'dlx')) i = 2;
  else if (b === 'yarn' && ws[1] === 'dlx') i = 2;
  else return 0;
  while (i < ws.length && ws[i].startsWith('-')) i += 1;
  return i;
}

function interpretadorProibido(seg) {
  const ws = valores(seg);
  const i = idxInterpretador(ws);
  if (i >= ws.length) return null;
  const bi = basename(ws[i]);
  if (bi === 'deno' && ws[i + 1] === 'eval') return '`deno eval` (interpretador inline) não é permitido ao subagente';
  if (!ehInterpretador(bi)) return null;
  const args = ws.slice(i + 1);
  const opcoes = [];
  for (const a of args) {
    if (!a.startsWith('-') || a === '-') break;
    opcoes.push(a);
  }
  const inline = `interpretador inline (${bi} com -e/-c/-p/…) não é permitido ao subagente — escreva o script no tmp e rode por caminho (REQ-H7-2)`;
  for (const o of opcoes) {
    if (o.startsWith('--')) {
      if (['--eval', '--print', '--input-type'].includes(o.split('=')[0])) return inline;
    } else if (/[epcrEi]/.test(o.slice(1))) {
      return inline;
    }
  }
  if (/^python/.test(bi) && opcoes.includes('-m')) {
    const mod = args[args.indexOf('-m') + 1];
    if (mod !== 'pytest') return `\`${bi} -m\` só com pytest (REQ-H7-2)`;
  }
  if (args.includes('-')) return `${bi} lendo o script do stdin (\`-\`) não é permitido ao subagente (REQ-H7-2)`;
  if (SHELLS.has(bi) && opcoes.some((o) => /^-[A-Za-z]*s[A-Za-z]*$/.test(o))) return `\`${bi} -s\` lê o script do stdin (REQ-H7-2)`;
  const semScript = args.every((a) => a.startsWith('-')) && !opcoes.includes('--test') && !opcoes.includes('-m');
  const stdin = seg.depoisDePipe || seg.heredocs.length > 0
    || seg.redirs.some((r) => r.direcao === 'entrada' && (r.fd === null || r.fd === 0));
  if (semScript && stdin) return `${bi} sem script lê o programa do stdin — não é permitido ao subagente (REQ-H7-2)`;
  return null;
}

function cdInvalido(segs, i) {
  const seg = segs[i];
  const args = seg.palavras.slice(seg.idxComando + 1).map((p) => p.valor);
  if (i !== 0) return '`cd` só como primeiro comando, na forma `cd <dir> && <comando>` (REQ-H7-2)';
  if (args.length === 0) return '`cd` sem argumento não é permitido ao subagente (REQ-H7-2)';
  if (args[0] === '-') return '`cd -` não é permitido ao subagente (REQ-H7-2)';
  if (seg.conector !== '&&') return '`cd` precisa ser seguido de `&&` (`cd <dir> && <comando>`) (REQ-H7-2)';
  return null;
}

function estrutura(segs, i, c) {
  const seg = segs[i];
  if (seg.subshell > 0 || seg.grupo > 0 || seg.controle) {
    return 'subshell ( … ), grupo { …; } ou palavra de controle (if/for/while…) não são permitidos ao subagente (REQ-H7-2)';
  }
  const marcada = palavrasDe(seg).find((p) => MARCAS.some((m) => p.marcas?.[m]));
  if (marcada) return `palavra com $, crase, glob, chaves ou ~ fora de aspas: ${marcada.cru} (REQ-H7-2)`;
  for (const h of seg.heredocs) {
    if (h.hereString) return 'here-string (<<<) não é permitido ao subagente (REQ-H7-2)';
    if (!h.citado) return "heredoc com terminador sem aspas: use <<'EOF' (REQ-H7-2)";
    if (!heredocEscreveArquivo(seg)) return "heredoc só para escrever arquivo (cat > arq <<'EOF' ou tee arq) (REQ-H7-2)";
  }
  for (const { nome, valor } of seg.atribuicoes) {
    const m = atribuicaoInvalida(nome, valor.valor, c);
    if (m) return m;
  }
  if (seg.comando === null) return null;
  const b = basename(seg.comando);
  if (WRAPPERS.has(seg.comando) || WRAPPERS.has(b)) return `\`${seg.comando}\` (wrapper, eval ou source) não é permitido ao subagente (REQ-H7-2)`;
  const inline = interpretadorProibido(seg);
  if (inline) return inline;
  if (b === 'cd') return cdInvalido(segs, i);
  return null;
}

// ───────────────────────── H7-3 lista ─────────────────────────

function casaComandosConfigurados(ws, c) {
  return c.config.subagente.comandos.some((item) => Array.isArray(item) && item.length > 0
    && !item.some((t) => BANIDOS_EM_COMANDOS.has(t) || t.includes('GABARITO_ALLOW_'))
    && item.every((t, k) => ws[k] === t));
}

function regraGitBranch(resto) {
  const comLista = resto.includes('--list');
  for (let k = 0; k < resto.length; k += 1) {
    const a = resto[k];
    const nome = a.split('=')[0];
    if (BRANCH_FLAGS.has(a)) continue;
    if (BRANCH_COM_VALOR.has(nome)) {
      if (!a.includes('=') && resto[k + 1] !== undefined && !resto[k + 1].startsWith('-')) k += 1;
      continue;
    }
    if (a.startsWith('-')) return `\`git branch ${nome}\` não é permitido ao subagente`;
    if (!comLista) return '`git branch <nome>` cria branch: use `git switch -c <nome>`';
  }
  return null;
}

function regraGitAdd(resto, seg, c) {
  const ops = resto.filter((a) => a !== '--');
  if (ops.length === 0) return '`git add` sem arquivo';
  for (const a of ops) {
    if (a.startsWith('-')) return `\`git add ${a.split('=')[0]}\` não é permitido ao subagente (só arquivos nomeados)`;
    for (const dir of dirsDe(seg, c)) {
      const abs = dir === null ? null : normalizar(a, dir, c);
      if (abs === null || !ehArquivoRegular(abs)) return `\`git add ${a}\`: só arquivos regulares existentes (sem diretório, sem pathspec)`;
    }
  }
  return null;
}

function regraGitCommit(resto) {
  if (resto.length === 0 || resto.length % 2 !== 0) return '`git commit` só com `-m <texto>`';
  for (let k = 0; k < resto.length; k += 2) {
    if (resto[k] !== '-m') return '`git commit` só com `-m <texto>` (sem -n, -a, --amend, -F…)';
  }
  return null;
}

function regraGitRestore(resto) {
  const ops = resto.filter((a) => !['--staged', '--worktree', '--'].includes(a));
  if (ops.length === 0) return '`git restore` sem caminho';
  const opc = ops.find((a) => a.startsWith('-'));
  return opc ? `\`git restore ${opc.split('=')[0]}\` não é permitido (só --staged/--worktree)` : null;
}

function regraGit(args, seg, c) {
  let i = 0;
  while (i < args.length && args[i].startsWith('-')) {
    if (args[i] === '--no-pager') i += 1;
    else if (args[i] === '-C') i += 2;
    else return `opção global \`${args[i].split('=')[0]}\` de git não é permitida ao subagente`;
  }
  const sub = args[i];
  const resto = args.slice(i + 1);
  const recusada = resto.find((a, k) => GIT_RECUSADAS.test(a) && !(a === '-c' && k === 0 && (sub === 'switch' || sub === 'checkout')));
  if (recusada) return `opção \`${recusada.split('=')[0]}\` de git não é permitida ao subagente`;
  if (GIT_LEITURA.has(sub)) return null;
  switch (sub) {
    case 'stash': return resto[0] === 'list' && resto.length === 1 ? null : '`git stash` (exceto `stash list`) não é permitido ao subagente';
    case 'worktree': return resto[0] === 'list' ? null : '`git worktree` (exceto `worktree list`) não é permitido ao subagente';
    case 'branch': return regraGitBranch(resto);
    case 'add': return regraGitAdd(resto, seg, c);
    case 'commit': return regraGitCommit(resto);
    case 'switch':
      return resto.length === 2 && (resto[0] === '-c' || resto[0] === '-b') && !resto[1].startsWith('-')
        ? null : '`git switch` só como `git switch -c <nome>`';
    case 'checkout':
      if (resto.length === 2 && (resto[0] === '-b' || resto[0] === '-c') && !resto[1].startsWith('-')) return null;
      if (resto[0] === '--' && resto.length > 1) return null;
      return '`git checkout` só como `checkout -b <nome>` ou `checkout -- <caminhos>`';
    case 'restore': return regraGitRestore(resto);
    default: return `\`git ${sub ?? ''}\` fora da lista do subagente`;
  }
}

function regraGh(args) {
  const [g, a, ...resto] = args;
  if (!GH_OK.get(g)?.has(a)) return `\`gh ${g ?? ''} ${a ?? ''}\` fora da lista do subagente (só pr view|list|checks|diff|status, run list|view)`;
  for (let k = 0; k < resto.length; k += 1) {
    const o = resto[k];
    if (!o.startsWith('-')) continue;
    if (GH_SEM_VALOR.has(o)) continue;
    const nome = o.split('=')[0];
    if (GH_COM_VALOR.has(nome)) {
      if (!o.includes('=')) k += 1;
      continue;
    }
    return `opção \`${nome}\` de gh fora da lista do subagente`;
  }
  return null;
}

const JQ_COM_VALOR = new Set(['--indent', '-L']);
const JQ_COM_DOIS = new Set(['--arg', '--argjson']);
/** Builtin `env`/`$ENV`, `input_filename`, `$__loc__` no PROGRAMA de jq; `.env` (campo) e `config/env.json` (arquivo) não. */
const RE_JQ_AMBIENTE = /(?<![.\w$/-])env\b|\$ENV\b|\binput_filename\b|\$__loc__/;

/** Programa de jq: 1º operando, ou o arquivo de -f/--from-file (não inspecionado: lido do disco, fica em H7-4). */
function programaJq(args) {
  for (let k = 0; k < args.length; k += 1) {
    const a = args[k];
    if (a === '-f' || a === '--from-file') return null;
    if (JQ_COM_DOIS.has(a)) { k += 2; continue; }
    if (JQ_COM_VALOR.has(a)) { k += 1; continue; }
    if (!a.startsWith('-')) return a;
  }
  return null;
}

function regraJq(args) {
  if (args.some((a) => a.startsWith('--rawfile') || a.startsWith('--slurpfile'))) return '`jq --rawfile|--slurpfile` não é permitido ao subagente';
  const prog = programaJq(args);
  if (prog !== null && RE_JQ_AMBIENTE.test(prog)) return 'programa de `jq` com env, $ENV, input_filename ou $__loc__ não é permitido ao subagente';
  return null;
}

function ehBuscaRecursiva(cmd, args) {
  if (cmd === 'rg') return true;
  return args.some((a, k) => a === '--recursive' || a === '--directories=recurse'
    || (a === '-d' && args[k + 1] === 'recurse') || (!a.startsWith('--') && /^-[A-Za-z]*[rR]/.test(a)));
}

/** Opções de grep/rg cujo valor vem na palavra seguinte (o valor não é operando). */
const BUSCA_COM_VALOR = new Set([
  '-e', '-f', '-A', '-B', '-C', '-m', '-d', '-D', '-t', '-T', '-g', '-j', '-M',
  '--regexp', '--file', '--after-context', '--before-context', '--context', '--max-count', '--type', '--type-not',
  '--glob', '--iglob', '--threads', '--max-columns', '--directories', '--devices', '--include', '--exclude',
]);

/** Operandos de caminho de uma busca (A12): tira opções e seus valores; sem -e/-f/--regexp/--file (e fora de
 *  `rg --files`), o 1º operando é o PADRÃO e não conta como caminho. */
function operandosDeBusca(cmd, args) {
  const ops = [];
  let padraoPorOpcao = cmd === 'rg' && args.includes('--files');
  for (let k = 0; k < args.length; k += 1) {
    const a = args[k];
    if (a === '--') { ops.push(...args.slice(k + 1)); break; }
    if (!a.startsWith('-') || a === '-') { ops.push(a); continue; }
    const nome = a.split('=')[0];
    if (['-e', '-f', '--regexp', '--file'].includes(nome) || /^-[A-Za-z]*[ef].+/.test(a)) padraoPorOpcao = true;
    if (BUSCA_COM_VALOR.has(a)) k += 1;
  }
  return padraoPorOpcao ? ops : ops.slice(1);
}

function regraBusca(cmd, args, seg, c) {
  if (cmd === 'rg' && args.some((a) => /^--(pre|pre-glob|search-zip)(=|$)/.test(a) || (!a.startsWith('--') && /^-[A-Za-z]*z/.test(a)))) {
    return '`rg --pre|--pre-glob|--search-zip|-z` não é permitido ao subagente';
  }
  if (!ehBuscaRecursiva(cmd, args)) return null;
  const raizes = raizesDe(c);
  let caminhos = 0;
  for (const a of operandosDeBusca(cmd, args)) {
    if (a === '.' || a === './' || a === '..' || a === '../') return `busca recursiva em \`${a}\`: passe um subdiretório nomeado`;
    for (const dir of dirsDe(seg, c)) {
      const abs = dir === null ? null : normalizar(a, dir, c);
      if (abs !== null && raizes.has(semBarra(abs))) return 'busca recursiva na raiz do repositório: passe um subdiretório nomeado';
      if (abs !== null && existe(abs)) caminhos += 1;
    }
  }
  return caminhos > 0 ? null : 'busca recursiva exige ao menos um caminho existente (subdiretório nomeado)';
}

function regraFind(args, seg, c) {
  let k = 0;
  const partidas = [];
  while (k < args.length && !args[k].startsWith('-') && args[k] !== '!' && args[k] !== '(') {
    partidas.push(args[k]);
    k += 1;
  }
  if (partidas.length === 0) partidas.push('.');
  const raizes = raizesDe(c);
  for (const p of partidas) {
    for (const dir of dirsDe(seg, c)) {
      const abs = dir === null ? null : normalizar(p, dir, c);
      if (abs === null || abs === '/' || raizes.has(semBarra(abs))) return '`find` a partir de `/` ou da raiz do repositório: passe um subdiretório';
    }
  }
  for (; k < args.length; k += 1) {
    const a = args[k];
    if (FIND_COM_VALOR.has(a)) {
      k += 1;
      continue;
    }
    if (FIND_SEM_VALOR.has(a)) continue;
    return `predicado \`${a}\` de find fora da lista do subagente (-name -iname -path -ipath -type -maxdepth -mindepth -newer -print -not !)`;
  }
  return null;
}

function regraFerramentaJs(args) {
  return FERRAMENTAS_JS.has(args[0]) || (args[0] === 'playwright' && args[1] === 'test');
}

function regraGerenciador(cmd, args) {
  const [a0, a1] = args;
  if (a0 === 'test' || a0 === 'ci') return null;
  if (a0 === 'run' && (SCRIPTS_RUN.has(a1) || /^test:/.test(a1 ?? ''))) return null;
  if (a0 === 'install' && (a1 === '--frozen-lockfile' || a1 === '--immutable') && args.length === 2) return null;
  if (cmd === 'pnpm' && a0 === 'exec' && regraFerramentaJs(args.slice(1))) return null;
  if (cmd === 'yarn' && regraFerramentaJs(args)) return null;
  return `\`${cmd} ${a0 ?? ''}\` fora da lista do subagente`;
}

function regraNode(args) {
  if (args.includes('--test')) {
    return args.every((a) => !a.startsWith('-') || OPCAO_NODE_TEST.test(a))
      ? null : '`node --test` só com --test-reporter=, --test-reporter-destination=, --test-name-pattern=, --experimental-strip-types';
  }
  if (args[0] !== undefined && !args[0].startsWith('-') && /\.(mjs|js|cjs)$/.test(args[0])) return null;
  return '`node` só como `node --test …` ou `node <arquivo>.(mjs|js|cjs)`, sem opções do interpretador';
}

function listaEmbutida(ws, seg, c) {
  const [cmd, ...args] = ws;
  if (SIMPLES.has(cmd)) return null;
  switch (cmd) {
    case 'git': return regraGit(args, seg, c);
    case 'gh': return regraGh(args);
    case 'wc': return args.some((a) => a.startsWith('--files0-from')) ? '`wc --files0-from` não é permitido ao subagente' : null;
    case 'sort':
      return args.some((a) => a.startsWith('--output') || a.startsWith('--compress-program') || a.startsWith('--files0-from')
        || (!a.startsWith('--') && /^-[A-Za-z]*o/.test(a))) ? '`sort` com -o/--output/--compress-program/--files0-from não é permitido ao subagente' : null;
    case 'uniq': return args.filter((a) => !a.startsWith('-')).length > 1 ? '`uniq` com arquivo de saída não é permitido ao subagente' : null;
    case 'jq': return regraJq(args);
    case 'date': // -I[fmt] (e --iso-8601[=fmt]) leva o formato colado: `date -Iseconds` não é `-s`
      return args.some((a) => (!a.startsWith('--') && !a.startsWith('-I') && /^-[A-Za-z]*[fs]/.test(a)) || a.startsWith('--file') || a.startsWith('--set'))
        ? '`date -f|-s` não é permitido ao subagente' : null;
    case 'grep': case 'egrep': case 'rg': return regraBusca(cmd, args, seg, c);
    case 'find': return regraFind(args, seg, c);
    case 'sed':
      return args.length === 3 && args[0] === '-n' && /^\d+(,\d+)?p$/.test(args[1]) && !args[2].startsWith('-')
        ? null : "`sed` só na forma `sed -n '<N>[,<M>]p' <arquivo>`";
    case 'npm': case 'pnpm': case 'yarn': return regraGerenciador(cmd, args);
    case 'npx': return regraFerramentaJs(args) ? null : '`npx` só com jest|vitest|tsc|eslint|prettier|playwright test, sem opção do npx antes do nome';
    case 'node': return regraNode(args);
    case 'bash': return args[0] !== undefined && !args[0].startsWith('-') && args[0].endsWith('.sh') ? null : '`bash` só como `bash <arquivo>.sh`, sem opções';
    case 'python3':
      return (args[0] === '-m' && args[1] === 'pytest') || (args[0] !== undefined && !args[0].startsWith('-') && args[0].endsWith('.py'))
        ? null : '`python3` só como `python3 <arquivo>.py` ou `python3 -m pytest`';
    case 'pytest': return null;
    default: return `comando \`${cmd}\` fora da lista do subagente`;
  }
}

function lista(seg, c) {
  if (seg.comando === null) return null;
  const ws = valores(seg);
  if (casaComandosConfigurados(ws, c)) return null;
  const motivo = listaEmbutida(ws, seg, c);
  return motivo === null ? null : `${motivo} (REQ-H7-3; peça ao orquestrador para incluí-lo em subagente.comandos)`;
}

// ───────────────────────── H7-4 escopo ─────────────────────────

function escopo(seg, c) {
  const b = seg.comando === null ? null : basename(seg.comando);
  const leitor = LEITORES.has(b) || (b === 'sed' && seg.palavras.some((p) => p.valor === '-n'));
  const idxScript = b === 'node' || b === 'bash' || b === 'python3' ? seg.idxComando + 1 : -1;
  const palavraScript = idxScript >= 0 ? seg.palavras[idxScript] : undefined;
  for (const cand of candidatos(seg, c)) {
    if (cand.classe === 'verificavel' && !verificavelViraCandidato(cand, c, ehArquivoSegredo)) continue;
    const ehScript = palavraScript !== undefined && (cand.palavra === palavraScript || (cand.fonte === 'i' && cand.valor === palavraScript.valor));
    const porLeitura = !cand.destino && (leitor || ehScript);
    for (const abs of cand.abs) {
      if (abs === null) return `caminho \`${cand.valor}\` com diretório corrente desconhecido (REQ-H7-4)`;
      const ok = porLeitura ? noEscopoLeitura(abs, c) : noEscopoEscrita(abs, c);
      if (!ok) return `caminho fora do escopo de ${porLeitura ? 'leitura' : 'escrita'} do subagente: ${abs} (REQ-H7-4)`;
    }
  }
  return null;
}

// ───────────────────────── Bash/Monitor ─────────────────────────

function avaliarComando(payload, c) {
  const cmd = payload.command;
  if (typeof cmd !== 'string' || cmd.trim() === '') return negar('comando ausente ou ilegível (REQ-H0-2)', 'H0-2');
  if (!c.cwdExiste || !noEscopoEscrita(c.cwd, c)) return negar(`diretório corrente fora do escopo do subagente: ${c.cwd} (REQ-H7-4)`, 'H7-4');
  if (cmd.includes('GABARITO_ALLOW_')) return negar('GABARITO_ALLOW_* no comando de subagente (REQ-H7-2)', 'H7-2');
  let analise;
  try {
    analise = tokenizar(cmd);
  } catch (e) {
    if (e instanceof ErroIlegivel) return negar(`comando ilegível: ${e.message} (REQ-H0-2)`, 'H0-2');
    throw e;
  }
  anotarDiretorios(analise, c);
  const segs = analise.segmentos;
  for (let i = 0; i < segs.length; i += 1) {
    const m = estrutura(segs, i, c);
    if (m) return negar(m, 'H7-2');
  }
  for (const seg of segs) {
    const m = lista(seg, c);
    if (m) return negar(m, 'H7-3');
  }
  for (const seg of segs) {
    const m = escopo(seg, c);
    if (m) return negar(m, 'H7-4');
  }
  return allow();
}

export function avaliar(payload, ctx) {
  if (!ctx.s) return allow();
  const c = ctx.config ? ctx : { ...montarContexto(payload, process.env), sPeloCwd: ctx.sPeloCwd };
  const t = payload.toolName;
  if (MEDICOES.ferramentasDeControle.includes(t)) return allow();
  if (t === 'Bash' || t === 'Monitor') return avaliarComando(payload, c);
  if (t === 'Read') return leitura(payload.filePath, c, 'Read');
  if (t === 'Grep' || t === 'Glob') return busca(payload, c);
  if (t === 'Write' || t === 'Edit') return escrita(payload.filePath, c, t);

  if (t.startsWith('mcp__')) return avaliarMcp(payload, c);
  return negar(`ferramenta ${t} fora da lista do subagente (REQ-H7-1)`, 'H7-1');
}
