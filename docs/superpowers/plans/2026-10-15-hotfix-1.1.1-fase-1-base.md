# Gabarito Mestre 1.1.1 — Fase 1: base (T0–T4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Medir as cinco incógnitas da spec (T0) e construir a base sobre a qual as guardas novas são escritas: leitura de payload, configuração, contexto O×S, decisão/emissão e wrapper sem node (T1); tokenizador de shell (T2); raízes, escopos, `cd` e candidatos de caminho (T3); e, em bash, payload/S/hatch/sufixo/raiz principal em `_common.sh`, POS em qualquer ordem em R2/R20 e identificadores de produção em R3 (T4).

**Architecture:** Duas camadas (D10). Node: `hooks/lib/{medicoes,payload,config,contexto,decisao,palavras,caminhos}.mjs`, todas puras exceto `lerStdin`/`rodarGuarda`/`raizes` (git) e a checagem de existência; testadas por `node:test` direto e por processos reais (`rodarNode`) contra guardas-fixture em `hooks/test/fixtures/`. Nada desta fase é registrado no `hooks.json` (T12).

**Tech Stack:** Node `>=22.18` (ESM, `node --test`, `node:assert/strict`, `node:fs|path|os|child_process`), bash 3.2 (macOS) e bash 5 (CI), `jq`/`node`/`python3` como parsers do bash, zero dependências npm.

## Decisões desta fase sobre pontos que a spec deixa abertos

| # | Linha da spec | Decisão |
|---|---|---|
| F1 | l.57 (heredoc) | "Só escreve arquivo" = comando efetivo `cat` sem operandos ou `tee`, **e o segmento não é seguido de `\|`** — inclui `cat <<'EOF'` dentro de `$( … )` (mensagem de commit é dado, não comando). Corpo citado desses ⇒ `corpoAnalise = null`; corpo sem aspas ⇒ só as substituições (`$( … )`, crase), que são o que o bash executa. Shell lendo stdin (`bash`, `sh`, `zsh`, `dash`, `ksh` sem `-c` e sem script) ⇒ corpo tokenizado **estrito**. Qualquer outro programa (`python3`, `psql`, `cat … \| bash`) ⇒ corpo tokenizado **tolerante** (+ substituições, se sem aspas). |
| F2 | l.56 (REQ-H0-7) | A frase "rode fora do auto mode ou peça ao usuário `! <comando>`" vai só no deny. Ferramenta sem chave em `askChegaEmAuto` (`Monitor`, `Read`…) = "não chega" (conservador). |
| F3 | l.59 (v) · **r22 E7** | `-o` não é flag de saída em `grep\|egrep\|rg\|ag\|ack\|git grep` (lá é `--only-matching`) — ratificado pela spec em r22 E7 (não é mais reinterpretação do plano). Em `find`, a expressão inteira fica fora dos candidatos, salvo o arquivo de `-fprint\|-fprint0\|-fprintf\|-fls` (destino). (v) vence texto verificável; texto puro vence (v). Palavra seguinte que começa com `-` não é valor de (v). |
| F4 | l.57 (`cd`) | Depois de `cd x &&`, o diretório anterior volta a ser possível assim que a cadeia `&&` termina por `;`, quebra de linha, `\|\|` ou `&` (`cd a && make; cat x` ⇒ {a, anterior}). `cd` em segmento com `&` (background) não propaga. |
| F5 | l.53–54 | `CLAUDE_PROJECT_DIR` entra em todo alvo "`<raiz>/…`" (H4-1, `.git/`, `.husky/`); não amplia escopo de escrita nem de leitura de S. |
| F6 | l.54 + RF3 | Pertença a escopo decide pela forma **física** do caminho contra a forma física das raízes (`/var/folders` ≡ `/private/var/folders`; symlink de dentro do worktree para fora fica fora). Exclusões (`.git`, `.husky`, H4-1) valem em qualquer forma. |
| F7 | l.163 | MH70/MH71 (`cd`) estão na linha H0-8 e o plano-mestre os lista na T2, mas o contrato põe `anotarDiretorios` em `caminhos.mjs` (T3). Testes e mutações de MH70/MH71 ficam na T3. |

| F10 | l.78 (REQ-H2-5) | `producaoAusente` = nenhuma das duas chaves (`producao.mcp.servidores`, `producao.identificadores`) é array em nenhuma das duas cópias. |
| F11 | l.71 (REQ-H1-4) | R20 aceita em qualquer ordem atribuições e os wrappers que já aceitava (`time\|env\|command`); R2 mantém seu conjunto de wrappers (`sudo\|exec\|time\|nice\|command\|env\|xargs\|nohup\|caffeinate\|timeout N`). |
| F12 | l.79 (REQ-H2-6) | Identificador casa por `grep -F` (literal, sensível a caixa) no texto varrido (`gabarito_scan_text` — `grep`/`echo`/`git commit -m` não contam), depois dos padrões; `GABARITO_PROD_PATTERNS` não desliga os identificadores. A mensagem não ecoa o identificador. |
| F13 | l.49 (REQ-H0-1) | No bash, o comando é o **último** campo do payload lido por NUL e todo NUL interno vira quebra de linha (jq `split("\u0000") \| join("\n")`, node `.replace(/\0/g, "\n")`, python3 `.replace("\0", "\n")`). ## Global Constraints

- Node `>=22.18`; ESM; **zero dependências** (`gates/package.json` `dependencies: {}` segue vazio). Bibliotecas novas em `plugins/gabarito-mestre/hooks/lib/*.mjs`.
- Bash compatível com **3.2**: sem `mapfile`, sem `declare -A`, sem `${var,,}`; `read -d ''` e `< <( … )` são 3.2.
- Saída de hook: allow = exit 0 sem stdout; ask = exit 0 com `{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"ask","permissionDecisionReason":…}}`; deny = exit **2** com o mesmo JSON (`"deny"`) e o motivo em stderr. Erro interno de hook node ⇒ deny exit 2 (REQ-H0-6).
- Toda negação para S termina com: `subagente não usa escape hatch nem contorna bloqueio — devolva ao orquestrador o comando e o motivo` (REQ-H1-2).
- Config lida de `RAIZ_PRINCIPAL/harness.config.json` (REQ-H0-4); de `RAIZ_WT` só se **acrescentam** `producao.mcp.servidores` e `producao.identificadores`. R20 continua em `RAIZ_WT`.
- Forma de nome de `subagente.env`: `^(PORT|[A-Z][A-Z0-9_]*_(PORT|SCHEMA|NAMESPACE|PREFIX|SUFFIX))$`.
- Nenhum segredo, token ou valor de variável de ambiente em log, stderr ou mensagem de hook — só nomes. Exceção capturada em guarda node vira mensagem com o **nome** da exceção, nunca a mensagem.
- Texto voltado ao usuário em português do Brasil.
- Fixtures de teste **fora** de `$TMPDIR`, `/tmp` e `/private/tmp` (escopo de escrita de S): `FIXTURES_BASE` = `~/.cache/gabarito-mestre-testes` (sobrescrevível por `GM_FIXTURES_BASE`).

## Review Focus

Do plano-mestre, atribuídos a esta fase (cada um tem teste na task dona):

1. **RF2 — comando enorme ou malformado não trava** (T2): heredoc de 200 KB, 10.000 `;`, byte nulo, UTF-8 inválido, 10.000 parênteses aninhados ⇒ < 1 s, legível ou `ErroIlegivel`.
2. **RF3 — caminho com espaço e symlink de tmp no macOS** (T3): `/var/folders/…` ≡ `/private/var/folders/…`; `"…/My Repo/a.txt"`.
3. **RF4 — repo sem git, `cwd` apagado ou inexistente** (T3): raízes = `cwd`, `cwdExiste:false`, sem chamar git.

Próprios desta fase (entradas que nenhuma linha de §6 exercita e que mais mordem):

5. **Mensagem de commit por `$(cat <<'EOF' … EOF)` citando `.env` ou caminhos** não pode virar comando (é o padrão de commit do Claude Code): `corpoAnalise = null` (T2, teste "mensagem de commit … é dado").
6. **Heredoc de Python com apóstrofo** (`python3 - <<'PY'` com `"it's"`) não pode ficar ilegível ⇒ deny para O em toda guarda node (T2, teste "corpo de outro programa").
7. **Suíte rodando dentro de worktree `agent-*`** (execução subagent-driven com `isolation: worktree`): payload sem `cwd` explícito não pode cair no fallback de REQ-H0-3 e virar S (T1, teste "payload sem cwd usa diretório neutro").

9. **Parser do bash**: `jq` ausente (máquina sem jq), payload com tipo errado (`tool_input: []`, `agent_id: 7`) ou `\u0000` dentro do comando — os três parsers devolvem os mesmos seis campos, com `agent_id` intacto e o resto do comando visível (T4, decisão F13).

function decisaoDe(r, quem) {
  if (r.status === 2) return 'deny';
  if (r.status === 0) {
    const out = (r.stdout || '').trim();
    if (!out) return 'allow';
    let j;
    try { j = JSON.parse(out.split('\n').pop()); } catch { throw new Error(`${quem}: stdout não é JSON: ${out.slice(0, 200)}`); }
    const pd = j?.hookSpecificOutput?.permissionDecision;
    if (pd === 'ask') return 'ask';
    if (pd === undefined && j.systemMessage) return 'allow'; // escape hatch de R2/R3/R20: exit 0 + systemMessage
    throw new Error(`${quem}: exit 0 com decisão inesperada: ${out.slice(0, 200)}`);
  }
  throw new Error(`${quem}: código de saída ${r.status} (sinal ${r.signal}); stderr: ${(r.stderr || '').slice(0, 300)}`);
}

 *   pattern:string|null, glob:string|null, url:string|null }} Payload */

/** → Payload | null (null = ilegível: não JSON, sem tool_name ou sem tool_input objeto) */
export function lerPayload(texto) {
  if (typeof texto !== 'string') return null;
  let j;
  try { j = JSON.parse(texto); } catch { return null; }
  if (!j || typeof j !== 'object' || Array.isArray(j)) return null;
  if (typeof j.tool_name !== 'string' || j.tool_name === '') return null;
  const ti = j.tool_input;
  if (!ti || typeof ti !== 'object' || Array.isArray(ti)) return null;
  return {
    toolName: j.tool_name,
    agentId: str(j.agent_id),
    agentType: str(j.agent_type),
    permissionMode: str(j.permission_mode),
    cwd: str(j.cwd),
    sessionId: str(j.session_id),

    filePath: strOuNull(ti.file_path),
    notebookPath: strOuNull(ti.notebook_path),
    path: strOuNull(ti.path),
    pattern: strOuNull(ti.pattern),
    glob: strOuNull(ti.glob),
    url: strOuNull(ti.url),
  };
}

/** → string (stdin inteiro, UTF-8; byte inválido vira U+FFFD) */
export async function lerStdin() {
  const partes = [];
  for await (const p of process.stdin) partes.push(typeof p === 'string' ? Buffer.from(p) : p);
  return Buffer.concat(partes).toString('utf8');
}

export const ALLOW = Object.freeze({ tipo: 'allow', motivo: '', regra: '' });
export const SUFIXO_S = 'subagente não usa escape hatch nem contorna bloqueio — devolva ao orquestrador o comando e o motivo';

export function ask(motivo, regra) { return { tipo: 'ask', motivo: String(motivo), regra: String(regra) }; }

/**

 * (conservador). O 5º parâmetro existe para teste (simular M-A); produção usa MEDICOES.

export function askOuDeny(payload, ferramenta, motivo, regra, medicoes = MEDICOES) {
  const chave = String(ferramenta).startsWith('mcp__') ? 'mcp' : String(ferramenta);
  if (medicoes.askChegaEmAuto[chave] === true) return ask(motivo, regra);
  if (payload && payload.permissionMode === MODO_AUTO) return deny(`${motivo} — ${MSG_FORA_DO_AUTO}`, regra);
  return ask(motivo, regra);
}

const PESO = { allow: 0, ask: 1, deny: 2 };
/** deny > ask > allow; vence o 1º motivo do tipo vencedor. Lista vazia = allow. */
export function compor(decisoes) {
  let v = ALLOW;
  for (const d of decisoes) if (d && PESO[d.tipo] > PESO[v.tipo]) v = d;
  return v;
}

function motivoFinal(decisao, { s, sPeloCwd }) {
  if (!s) return decisao.motivo;
  const base = decisao.motivo.endsWith(SUFIXO_S) ? decisao.motivo.slice(0, -SUFIXO_S.length).replace(/[\s—]+$/, '') : decisao.motivo;
  const partes = [base];
  if (sPeloCwd) partes.push(MSG_PELO_CWD);
  partes.push(SUFIXO_S);
  return partes.filter(Boolean).join(' — ');
}

/** Escreve stdout/stderr e define process.exitCode (0 ou 2). Não chama process.exit. */
export function emitir(decisao, { s = false, sPeloCwd = false } = {}) {
  if (!decisao || decisao.tipo === 'allow') { process.exitCode = 0; return; }
  const motivo = motivoFinal(decisao, { s, sPeloCwd });
  const tipo = decisao.tipo === 'ask' ? 'ask' : 'deny';
  process.stdout.write(JSON.stringify({ hookSpecificOutput: { hookEventName: 'PreToolUse', permissionDecision: tipo, permissionDecisionReason: motivo } }) + '\n');
  if (tipo === 'deny') {
    process.stderr.write(`gabarito-mestre [${decisao.regra}]: ${motivo}\n`);
    process.exitCode = 2;
  } else {
    process.exitCode = 0;
  }
}

const RE_AGENT_ID_TEXTO = /"agent_id"\s*:\s*"[^"]/;

/** main padrão das guardas node. Nunca deixa exceção escapar: erro ⇒ deny exit 2 (REQ-H0-6). */
export async function rodarGuarda(avaliar, { leve = false } = {}) {
  let s = false;
  let sPeloCwd = false;
  try {
    const texto = await lerStdin();
    const payload = lerPayload(texto);
    if (!payload) {
      s = RE_AGENT_ID_TEXTO.test(texto);
      emitir(deny('entrada ilegível (stdin não é JSON de PreToolUse com tool_name e tool_input) — negado por segurança (REQ-H0-2)', 'H0-2'), { s });
      return;
    }
    const ctx = leve ? contextoLeve(payload) : montarContexto(payload);
    s = ctx.s;
    sPeloCwd = ctx.sPeloCwd;
    for (const a of ctx.config?.avisos ?? []) process.stderr.write(`gabarito-mestre: ${a}\n`);
    const decisao = await avaliar(payload, ctx);
    emitir(decisao ?? ALLOW, { s, sPeloCwd });
  } catch (e) {
    if (e && e.name === 'ErroIlegivel') {
      emitir(deny(`comando ilegível (${e.message}) — negado por segurança (REQ-H0-2)`, 'H0-2'), { s, sPeloCwd });
    } else {
      emitir(deny(`erro interno da guarda (${e && e.name ? e.name : 'erro'}) — negado por segurança (REQ-H0-6)`, 'H0-6'), { s, sPeloCwd });
    }
  }
}

describe('aspas e escapes', () => {
  test("aspas adjacentes (MH9): cat '.en''v' → palavra .env", () => {
    assert.deepEqual(valores("cat '.en''v'"), ['cat', '.env']);
    assert.deepEqual(valores('cat ".e"n\'v\''), ['cat', '.env']);
    assert.deepEqual(valores('cat .e\\nv'), ['cat', '.env']);
  });
  test('a\\ b → uma palavra "a b"; \\+quebra de linha junta', () => {
    assert.deepEqual(valores('ls a\\ b'), ['ls', 'a b']);
    assert.deepEqual(valores('ec\\\nho x'), ['echo', 'x']);

  test('aspas duplas: \\ escapa " \\ $ crase; o resto fica', () => {
    assert.deepEqual(valores('echo "a\\"b\\\\c\\$d\\`e\\n"'), ['echo', 'a"b\\c$d`e\\n']);

    assert.equal(seg("echo $'\\056env\\n\\u0041'").palavras[1].valor, '.env\nA');
  });

    assert.deepEqual(marcas(seg('ls .e[n]v').palavras[1]), ['glob']);
    assert.deepEqual(marcas(seg('ls "*"').palavras[1]), []);

    const c = s[i];
    if (c === "'") return [out, i + 1];
    if (c !== '\\') { out += c; i++; continue; }
    const e = s[i + 1];
    i += 2;
    const simples = { a: '\x07', b: '\b', e: '\x1b', E: '\x1b', f: '\f', n: '\n', r: '\r', t: '\t', v: '\v', '\\': '\\', "'": "'", '"': '"', '?': '?' };
    if (e in simples) { out += simples[e]; continue; }
    if (e === undefined) break;
    if (/[0-7]/.test(e)) {
      const m = /^[0-7]{1,3}/.exec(s.slice(i - 1, i + 2));
      out += String.fromCharCode(parseInt(m[0], 8));
      i += m[0].length - 1;
      continue;
    }
    const hex = { x: 2, u: 4, U: 8 }[e];
    if (hex) {
      const m = new RegExp(`^[0-9A-Fa-f]{1,${hex}}`).exec(s.slice(i, i + hex));
      if (m) { out += String.fromCodePoint(parseInt(m[0], 16)); i += m[0].length; } else out += '\\' + e;
      continue;
    }
    if (e === 'c' && i < n) { out += String.fromCharCode(s.charCodeAt(i) & 0x1f); i++; continue; }
    out += '\\' + e;
  }
  if (tolerante) return [out, n];
  throw new ErroIlegivel("$'…' sem aspa de fechamento");
}

class Leitor {
  constructor(s, inicio, prof, tolerante) {
    if (prof > PROFUNDIDADE_MAX) throw new ErroIlegivel('mais de 3 níveis de substituição/bash -c');
    this.s = s;
    this.i = inicio;
    this.n = s.length;
    this.prof = prof;
    this.tol = tolerante;
    this.pendentes = []; // heredocs aguardando o corpo: { h, seg, tab }
    this.ligacoes = []; // heredocs com corpo lido: { h, seg }
    this.emCondicional = false; // dentro de [[ … ]]
  }

  falhar(msg) {
    if (!this.tol) throw new ErroIlegivel(msg);
  }

  sub(inicio) {
    return new Leitor(this.s, inicio, this.prof + 1, this.tol);
  }

  // ── palavras ───────────────────────────────────────────────────────────────────────────
  /** Lê uma palavra a partir de this.i. Para em metacaractere fora de aspas. */
  lerPalavra() {
    const ini = this.i;
    const p = { valor: '', cru: '', marcas: marcasVazias(), internos: [] };
    const s = this.s;
    // substituição de processo <(…) / >(…) no início da palavra
    if ((s[this.i] === '<' || s[this.i] === '>') && s[this.i + 1] === '(') {
      const r = this.sub(this.i + 2).analisar(true);
      p.internos.push(r.analise);
      p.marcas.substituicao = true;
      this.i = r.fim + 1;
      p.valor += s.slice(ini, this.i);
    }
    while (this.i < this.n) {
      const c = s[this.i];
      if (BRANCO.has(c) || c === '\n') break;
      if (META.has(c) && !(this.emCondicional && '&|<>()'.includes(c))) break;
      if (c === '\\') {
        if (s[this.i + 1] === '\n') { this.i += 2; continue; }
        if (this.i + 1 >= this.n) { p.valor += '\\'; this.i++; continue; }
        p.valor += s[this.i + 1];
        this.i += 2;
        continue;
      }
      if (c === "'") {
        const j = s.indexOf("'", this.i + 1);
        if (j < 0) { this.falhar('aspas simples sem fechamento'); p.valor += s.slice(this.i + 1); this.i = this.n; break; }
        p.valor += s.slice(this.i + 1, j);
        this.i = j + 1;
        continue;
      }
      if (c === '"') { this.i++; this.lerAspasDuplas(p, true); continue; }
      if (c === '$') { this.lerDolar(p, false); continue; }
      if (c === '`') { this.lerCrase(p); continue; }
      if (c === '*' || c === '?' || c === '[') p.marcas.glob = true;
      if (c === '{') p.marcas.chaves = true;
      if (c === '~' && (p.valor === '' || (p.valor.endsWith('=') && p.valor.indexOf('=') === p.valor.length - 1))) p.marcas.til = true;
      p.valor += c;
      this.i++;
    }
    p.cru = s.slice(ini, this.i);
    if (COLCHETES.has(p.cru)) p.marcas.glob = false;
    return p;
  }

  /** Conteúdo entre aspas duplas (this.i já depois da "). Com `fechar=false`, lê até o fim (corpo de heredoc sem aspas). */
  lerAspasDuplas(p, fechar) {
    const s = this.s;
    while (this.i < this.n) {
      const c = s[this.i];
      if (c === '"' && fechar) { this.i++; return; }
      if (c === '\\') {
        const e = s[this.i + 1];
        if (e === '\n') { this.i += 2; continue; }
        if (e === '"' || e === '\\' || e === '$' || e === '`') { p.valor += e; this.i += 2; continue; }
        p.valor += '\\';
        this.i++;
        continue;
      }
      if (c === '$') { this.lerDolar(p, true); continue; }
      if (c === '`') { this.lerCrase(p); continue; }
      p.valor += c;
      this.i++;
    }
    if (fechar) this.falhar('aspas duplas sem fechamento');
  }

  /** `$` em this.i. `dentroDeAspas` desliga $'…' e $"…". */
  lerDolar(p, dentroDeAspas) {
    const s = this.s;
    const ini = this.i;
    const prox = s[this.i + 1];
    if (prox === '(' && s[this.i + 2] === '(') {
      this.i = this.fimAritmetica(this.i + 3);
      p.marcas.expansao = true;
      p.valor += s.slice(ini, this.i);
      return;
    }
    if (prox === '(') {
      const r = this.sub(this.i + 2).analisar(true);
      p.internos.push(r.analise);
      p.marcas.expansao = true;
      p.marcas.substituicao = true;
      this.i = r.fim + 1;
      p.valor += s.slice(ini, this.i);
      return;
    }
    if (prox === '{') {
      this.i = this.fimParametro(this.i + 2, p);
      p.marcas.expansao = true;
      p.valor += s.slice(ini, this.i);
      return;
    }
    if (prox === "'" && !dentroDeAspas) {
      const [txt, fim] = decodificarAnsiC(s, this.i + 2, this.tol);
      p.valor += txt;
      p.marcas.expansao = true;
      this.i = fim;
      return;
    }
    if (prox === '"' && !dentroDeAspas) {
      this.i += 2;
      p.marcas.expansao = true;
      this.lerAspasDuplas(p, true);
      return;
    }
    const m = /^[A-Za-z_][A-Za-z0-9_]*/.exec(s.slice(this.i + 1, this.i + 256));
    if (m) {
      p.valor += '$' + m[0];
      p.marcas.expansao = true;
      this.i += 1 + m[0].length;
      return;
    }
    if (prox !== undefined && /[0-9?!#@*$-]/.test(prox)) {
      p.valor += '$' + prox;
      p.marcas.expansao = true;
      this.i += 2;
      return;
    }
    p.valor += '$';
    this.i++;
  }

  /** Crase em this.i: conteúdo tokenizado recursivamente. */
  lerCrase(p) {
    const s = this.s;
    let j = this.i + 1;
    let conteudo = '';
    while (j < this.n && s[j] !== '`') {
      if (s[j] === '\\' && (s[j + 1] === '`' || s[j + 1] === '\\' || s[j + 1] === '$')) { conteudo += s[j + 1]; j += 2; continue; }
      conteudo += s[j];
      j++;
    }
    if (j >= this.n) { this.falhar('crase sem fechamento'); j = this.n - 1; }
    p.internos.push(tokenizar(conteudo, { profundidade: this.prof + 1, tolerante: this.tol }));
    p.marcas.expansao = true;
    p.marcas.substituicao = true;
    p.valor += s.slice(this.i, j + 1);
    this.i = j + 1;
  }

  /** $(( … )) ou (( … )): índice depois do )) que fecha. Sem recursão (REQ-H0-8). */
  fimAritmetica(i) {
    let prof = 2;
    const s = this.s;
    while (i < this.n) {
      const c = s[i];
      if (c === '(') prof++;
      else if (c === ')') { prof--; if (prof === 0) return i + 1; }
      i++;
    }
    this.falhar('expansão aritmética sem fechamento');
    return this.n;
  }

  /** ${ … }: índice depois da } que fecha; $( … ) e crase internos vão para p.internos. */
  fimParametro(i, p) {
    let prof = 1;
    const s = this.s;
    while (i < this.n) {
      const c = s[i];
      if (c === '\\') { i += 2; continue; }
      if (c === "'") { const j = s.indexOf("'", i + 1); if (j < 0) break; i = j + 1; continue; }
      if (c === '"') {
        const q = { valor: '', cru: '', marcas: marcasVazias(), internos: [] };
        this.i = i + 1;
        this.lerAspasDuplas(q, true);
        p.internos.push(...q.internos);
        if (q.marcas.substituicao) p.marcas.substituicao = true;
        i = this.i;
        continue;
      }
      if (c === '$' && s[i + 1] === '(') {
        const q = { valor: '', cru: '', marcas: marcasVazias(), internos: [] };
        this.i = i;
        this.lerDolar(q, true);
        p.internos.push(...q.internos);
        if (q.marcas.substituicao) p.marcas.substituicao = true;
        i = this.i;
        continue;
      }
      if (c === '`') {
        const q = { valor: '', cru: '', marcas: marcasVazias(), internos: [] };
        this.i = i;
        this.lerCrase(q);
        p.internos.push(...q.internos);
        p.marcas.substituicao = true;
        i = this.i;
        continue;
      }
      if (c === '{') prof++;
      else if (c === '}') { prof--; if (prof === 0) return i + 1; }
      i++;
    }
    this.falhar('${ sem } de fechamento');
    return this.n;
  }

  // ── heredocs ───────────────────────────────────────────────────────────────────────────
  lerCorposPendentes() {
    const s = this.s;
    for (const pend of this.pendentes) {
      let corpo = '';
      let achou = false;
      while (this.i < this.n) {
        let fim = s.indexOf('\n', this.i);
        if (fim < 0) fim = this.n;
        const linha = s.slice(this.i, fim);
        this.i = fim < this.n ? fim + 1 : this.n;
        const cmp = pend.tab ? linha.replace(/^\t+/, '') : linha;
        if (cmp === pend.h.terminador) { achou = true; break; }
        corpo += linha + '\n';
      }
      if (!achou) this.falhar(`heredoc sem o terminador ${pend.h.terminador}`);
      pend.h.corpo = corpo;
      this.ligacoes.push(pend);
    }
    this.pendentes = [];
  }

  // ── segmentos ──────────────────────────────────────────────────────────────────────────
  /** Lê segmentos até o fim (ou até o `)` que fecha, com pararEmFecha). → { analise, fim } */
  analisar(pararEmFecha) {
    const s = this.s;
    const segmentos = [];
    const pilhaSub = [];
    let contSub = 0;
    let grupo = 0;
    const casos = []; // pilha de 'cabeca' | 'padrao' | 'corpo'
    let seg = null;

    const novo = () => ({
      palavras: [], atribuicoes: [], comando: null, idxComando: -1, redirs: [], heredocs: [], conector: null,
      seguidoDePipe: false, depoisDePipe: false, controle: false, palavrasControle: [], subshell: pilhaSub.length, subshells: [...pilhaSub],
      grupo, internos: [], cabeca: null,
    });
    seg = novo();
    const vazio = (g) => g.palavras.length === 0 && g.redirs.length === 0 && g.heredocs.length === 0 && !g.controle;
    const posComando = () => seg.comando === null && seg.cabeca === null;

    const fechar = (conector) => {
      if (vazio(seg)) {
        const ultimo = segmentos[segmentos.length - 1];
        if (conector) {
          // `( … ) && x`: o operador depois do `)` liga o último segmento do subshell
          if (ultimo && ultimo.conector === null) ultimo.conector = conector;
          else if (['&&', '||', '|', '|&'].includes(conector)) this.falhar(`operador ${conector} sem comando antes`);
        }
        seg = novo();
        return;
      }
      seg.conector = conector;
      finalizar(seg);
      segmentos.push(seg);
      seg = novo();
    };

    const finalizar = (g) => {
      delete g.cabeca;
      const cmd = nomeBase(g.comando);
      const args = g.idxComando >= 0 ? g.palavras.slice(g.idxComando + 1) : [];
      if (SHELLS.has(cmd)) {
        for (let k = 0; k < args.length; k++) {
          const v = args[k].valor;
          if (!v.startsWith('-')) break;
          if (/^-[A-Za-z]*c[A-Za-z]*$/.test(v) && k + 1 < args.length) {
            g.internos.push(tokenizar(args[k + 1].valor, { profundidade: this.prof + 1, tolerante: this.tol }));
            break;
          }
        }
      } else if (cmd === 'eval' && args.length) {
        g.internos.push(tokenizar(args.map((a) => a.valor).join(' '), { profundidade: this.prof + 1, tolerante: this.tol }));
      }
      for (const h of g.heredocs) if (h.hereString) h.corpoAnalise = this.analisarCorpo(h, g, h._palavra);
      for (const h of g.heredocs) delete h._palavra;
    };

    const adicionarPalavra = (p) => {
      const nu = !citada(p);
      // case: depois de `case X in`, padrão
      if (posComando() && seg.palavras.length === 0 && nu) {
        const ctl = seg.palavrasControle;
        if (casos.length && p.valor === 'esac') { casos.pop(); seg.controle = true; ctl.push('esac'); return; }
        if (PREFIXOS_CONTROLE.has(p.valor) || FECHOS_CONTROLE.has(p.valor)) { seg.controle = true; ctl.push(p.valor); return; }
        if (p.valor === '{') { grupo++; seg.grupo = grupo; ctl.push('{'); return; }
        if (p.valor === '}') {
          grupo--;
          if (grupo < 0) { this.falhar('} sem {'); grupo = 0; }
          seg.grupo = grupo;
          seg.controle = true;
          ctl.push('}');
          return;
        }
        if (CABECAS_CONTROLE.has(p.valor)) { seg.controle = true; seg.cabeca = p.valor; ctl.push(p.valor); return; }
      }
      if (seg.cabeca === 'function' && nu && p.valor === '{') {
        fechar(null);
        grupo++;
        seg.grupo = grupo;
        seg.palavrasControle.push('{');
        return;
      }
      seg.palavras.push(p);
      if (nu && p.valor === 'in' && ((seg.cabeca === 'case' && seg.palavras.length >= 2) || ((seg.cabeca === 'for' || seg.cabeca === 'select') && seg.palavras.length === 2))) {
        seg.palavrasControle.push('in');
      }
      if (seg.cabeca === 'case' && nu && p.valor === 'in' && seg.palavras.length >= 2) {
        fechar(null);
        casos.push('padrao');
        return;
      }
      if (!posComando()) return;
      const m = RE_ATRIBUICAO.exec(p.cru);
      if (m) {
        const k = p.cru.indexOf('=');
        const valorTxt = p.valor.slice(p.valor.indexOf('=') + 1);
        seg.atribuicoes.push({ nome: m[1], valor: { valor: valorTxt, cru: p.cru.slice(k + 1), marcas: p.marcas, internos: p.internos } });
        return;
      }
      seg.comando = p.valor;
      seg.idxComando = seg.palavras.length - 1;
      if (p.valor === '[[' && nu) this.emCondicional = true;
    };

    const lerPadraoDeCase = () => {
      // padrão: [(] palavra [| palavra]... )
      while (this.i < this.n && (BRANCO.has(s[this.i]) || s[this.i] === '\n')) this.i++;
      if (s[this.i] === '(') this.i++;
      for (;;) {
        while (this.i < this.n && BRANCO.has(s[this.i])) this.i++;
        if (this.i >= this.n) { this.falhar('case sem esac'); return; }
        const c = s[this.i];
        if (c === ')') { this.i++; casos[casos.length - 1] = 'corpo'; return; }
        if (c === '|') { this.i++; continue; }
        const salvo = this.emCondicional;
        this.emCondicional = false;
        const p = this.lerPalavra();
        this.emCondicional = salvo;
        if (p.cru === '') { this.falhar('padrão de case malformado'); this.i++; return; }
      }
    };

    while (this.i < this.n) {
      const c = s[this.i];
      if (BRANCO.has(c)) { this.i++; continue; }
      if (c === '\\' && s[this.i + 1] === '\n') { this.i += 2; continue; }
      if (c === '#') {
        const fim = s.indexOf('\n', this.i);
        this.i = fim < 0 ? this.n : fim;
        continue;
      }
      if (c === '\n') {
        this.i++;
        fechar('\n');
        this.lerCorposPendentes();
        continue;
      }
      if (casos.length && casos[casos.length - 1] === 'padrao' && posComando() && seg.palavras.length === 0) {
        // `esac` encerra; senão lê o padrão
        if (/^esac(?:[\s;&|)]|$)/.test(s.slice(this.i, this.i + 5))) {
          this.i += 4;
          casos.pop();
          seg.controle = true;
          seg.palavrasControle.push('esac');
          continue;
        }
        lerPadraoDeCase();
        continue;
      }
      if (this.emCondicional) {
        const p = this.lerPalavra();
        if (p.cru === '') { this.i++; continue; }
        seg.palavras.push(p);
        if (p.cru === ']]') this.emCondicional = false;
        continue;
      }
      if (c === ')') {
        if (pilhaSub.length) {
          this.i++;
          fechar(null);
          pilhaSub.pop();
          seg = novo();
          continue;
        }
        if (pararEmFecha) {
          fechar(null);
          this.verificarFim();
          return { analise: concluir(segmentos, this), fim: this.i };
        }
        this.falhar(') sem (');
        this.i++;
        continue;
      }
      if (c === '(') {
        if (s[this.i + 1] === '(' && posComando() && seg.palavras.length === 0) {
          const ini = this.i;
          this.i = this.fimAritmetica(this.i + 2);
          const p = { valor: s.slice(ini, this.i), cru: s.slice(ini, this.i), marcas: { ...marcasVazias(), expansao: true }, internos: [] };
          seg.palavras.push(p);
          seg.comando = p.valor;
          seg.idxComando = seg.palavras.length - 1;
          continue;
        }
        if (posComando() && seg.palavras.length === 0 && seg.atribuicoes.length === 0) {
          this.i++;
          pilhaSub.push(++contSub);
          seg = novo();
          continue;
        }
        const depois = /^\(\s*\)/.exec(s.slice(this.i, this.i + 32));
        if (depois && seg.palavras.length === 1) {
          this.i += depois[0].length;
          seg.controle = true;
          seg.comando = null;
          seg.idxComando = -1;
          fechar(null);
          continue;
        }
        this.falhar('( fora de posição de comando');
        this.i++;
        continue;
      }
      const op = /^(;;&|;;|;&|&&|\|\||\|&|;|&(?!>)|\|)/.exec(s.slice(this.i, this.i + 3));
      if (op) {
        this.i += op[0].length;
        if ((op[0] === ';;' || op[0] === ';&' || op[0] === ';;&') && casos.length && casos[casos.length - 1] === 'corpo') {
          fechar(';');
          casos[casos.length - 1] = 'padrao';
          continue;
        }
        fechar(op[0]);
        continue;
      }
      const r = (c === '<' || c === '>') && s[this.i + 1] === '(' ? null : RE_REDIR.exec(s.slice(this.i, this.i + 16));
      if (r) {
        this.i += r[0].length;
        this.lerRedirecionamento(seg, r[1] === undefined ? null : Number(r[1]), r[2]);
        continue;
      }
      const p = this.lerPalavra();
      if (p.cru === '') { this.falhar(`caractere inesperado ${JSON.stringify(c)}`); this.i++; continue; }
      adicionarPalavra(p);
    }
    fechar(null);
    if (pilhaSub.length) this.falhar('( sem )');
    if (grupo > 0) this.falhar('{ sem }');
    if (casos.length) this.falhar('case sem esac');
    if (pararEmFecha) this.falhar('$( sem )');
    this.verificarFim();
    return { analise: concluir(segmentos, this), fim: this.i };
  }

  verificarFim() {
    if (this.pendentes.length) {
      // terminador do heredoc nunca chegou (não houve quebra de linha depois de <<EOF)
      this.falhar(`heredoc sem corpo (${this.pendentes[0].h.terminador})`);
      for (const p of this.pendentes) { p.h.corpo = ''; this.ligacoes.push(p); }
      this.pendentes = [];
    }
  }

  lerRedirecionamento(seg, fd, op) {
    const s = this.s;
    while (this.i < this.n && BRANCO.has(s[this.i])) this.i++;
    // alvo `<(…)`/`>(…)` (acréscimo coordenado fases 1–2: `done < <(git ls-files -o)`): lerPalavra lê a substituição
    // de processo — alvo.marcas.substituicao = true e alvo.internos[0] = análise do comando interno. Não vale em heredoc.
    const subProc = !op.startsWith('<<') && (s[this.i] === '<' || s[this.i] === '>') && s[this.i + 1] === '(';
    const alvoTxt = this.i < this.n && (subProc || !META.has(s[this.i])) ? this.lerPalavra() : null;
    if (!alvoTxt || alvoTxt.cru === '') {
      this.falhar(`redirecionamento ${op} sem alvo`);
      return;
    }
    if (op === '<<' || op === '<<-') {
      const h = { citado: /['"\\]/.test(alvoTxt.cru), terminador: alvoTxt.valor, corpo: '', hereString: false, corpoAnalise: null };
      seg.heredocs.push(h);
      this.pendentes.push({ h, seg, tab: op === '<<-' });
      return;
    }
    if (op === '<<<') {
      seg.heredocs.push({ citado: /['"\\]/.test(alvoTxt.cru), terminador: '', corpo: alvoTxt.cru, hereString: true, corpoAnalise: null, _palavra: alvoTxt });
      return;
    }
    if (op === '>&' || op === '<&') {
      if (/^\d+$/.test(alvoTxt.valor) || alvoTxt.valor === '-') {
        seg.redirs.push({ op, fd, alvo: null, alvoFd: alvoTxt.valor === '-' ? null : Number(alvoTxt.valor), direcao: 'dup' });
      } else {
        seg.redirs.push({ op, fd, alvo: alvoTxt, alvoFd: null, direcao: op === '>&' ? 'saida' : 'entrada' });
      }
      return;
    }
    seg.redirs.push({ op, fd, alvo: alvoTxt, alvoFd: null, direcao: op === '<' ? 'entrada' : 'saida' });
  }

  /** Corpo de heredoc/here-string → Analise | null (REQ-H0-8; regras no plano da T2). */
  analisarCorpo(h, seg, palavraHereString) {
    const cmd = nomeBase(seg.comando);
    const args = seg.idxComando >= 0 ? seg.palavras.slice(seg.idxComando + 1) : [];
    const temC = args.some((a) => /^-[A-Za-z]*c[A-Za-z]*$/.test(a.valor));
    const operandos = args.filter((a) => !a.valor.startsWith('-'));
    const shellLeStdin = SHELLS.has(cmd) && !temC && (operandos.length === 0 || args.some((a) => a.valor === '-s'));
    const prof = this.prof + 1;
    if (h.hereString) {
      if (shellLeStdin) return tokenizar(palavraHereString.valor, { profundidade: prof, tolerante: this.tol });
      return { segmentos: palavraHereString.internos.flatMap((a) => a.segmentos) };
    }
    if (shellLeStdin) return tokenizar(h.corpo, { profundidade: prof, tolerante: this.tol });
    // `cat`/`tee` sem pipe só copiam o corpo (para arquivo ou para o texto de `$(…)`): o corpo é dado, não comando
    const seguidoDePipe = seg.conector === '|' || seg.conector === '|&';
    const soEscreve = !seguidoDePipe && ((cmd === 'cat' && operandos.length === 0) || cmd === 'tee');
    const subst = () => {
      const l = new Leitor(h.corpo, 0, prof, true);
      const p = { valor: '', cru: '', marcas: marcasVazias(), internos: [] };
      l.lerAspasDuplas(p, false);
      return p.internos.flatMap((a) => a.segmentos);
    };
    if (soEscreve) return h.citado ? null : { segmentos: subst() };
    const tolerante = tokenizar(h.corpo, { profundidade: prof, tolerante: true });
    if (h.citado) return tolerante;
    return { segmentos: [...tolerante.segmentos, ...subst()] };
  }
}

function concluir(segmentos, leitor) {
  for (let k = 0; k < segmentos.length; k++) {
    const g = segmentos[k];
    g.seguidoDePipe = g.conector === '|' || g.conector === '|&';
    g.depoisDePipe = k > 0 && segmentos[k - 1].seguidoDePipe;
  }
  for (const { h, seg } of leitor.ligacoes) h.corpoAnalise = leitor.analisarCorpo(h, seg, null);
  leitor.ligacoes = [];
  return { segmentos };
}

/** → Analise. Lança ErroIlegivel (aspas/heredoc/parêntese sem fechamento, byte nulo, profundidade > 3).
 *  `tolerante` (acréscimo ao contrato) não lança por fechamento ausente — usado só em corpo de heredoc de outro programa. */
export function tokenizar(comando, { profundidade = 0, tolerante = false } = {}) {
  if (typeof comando !== 'string') throw new ErroIlegivel('comando ausente');
  if (profundidade > PROFUNDIDADE_MAX) throw new ErroIlegivel('mais de 3 níveis de substituição/bash -c');
  if (comando.includes('\0')) throw new ErroIlegivel('byte nulo no comando');
  return new Leitor(comando, 0, profundidade, tolerante).analisar(false).analise;
}

// ── raízes (REQ-H0-4, M-C) ─────────────────────────────────────────────────────────────────
function git(cwd, args, env) {
  const limpo = { ...process.env, ...env };
  for (const k of ['GIT_DIR', 'GIT_WORK_TREE', 'GIT_INDEX_FILE', 'GIT_COMMON_DIR']) delete limpo[k];
  const r = spawnSync('git', ['-C', cwd, ...args], { encoding: 'utf8', timeout: 2000, env: limpo });
  return r.status === 0 ? r.stdout.trim() : '';
}

/** → { raizWT, raizPrincipal }. Fora de git (ou cwd inexistente): ambas = cwd. O 3º parâmetro existe para teste (simular M-C). */
export function raizes(cwd, env = process.env, medicoes = MEDICOES) {
  let existe = false;
  try { existe = lstatSync(cwd).isDirectory(); } catch { existe = false; }
  if (!existe) return { raizWT: cwd, raizPrincipal: cwd, semGit: true };
  const raizWT = git(cwd, ['rev-parse', '--show-toplevel'], env);
  if (!raizWT) return { raizWT: cwd, raizPrincipal: cwd, semGit: true };
  let raizPrincipal = '';
  if (medicoes.worktreeUsaGitCommonDir) {
    const comum = git(cwd, ['rev-parse', '--path-format=absolute', '--git-common-dir'], env);
    if (comum && basename(comum) === '.git') raizPrincipal = dirname(comum);
  }
  if (!raizPrincipal) {
    const lista = git(cwd, ['worktree', 'list', '--porcelain'], env);
    const m = /^worktree (.+)$/m.exec(lista);
    raizPrincipal = m ? m[1] : raizWT;
  }
  return { raizWT, raizPrincipal, semGit: false };

// ── normalização (REQ-H0-4) ────────────────────────────────────────────────────────────────
const RE_VAR = /\$\{([A-Za-z_][A-Za-z0-9_]*)\}|\$([A-Za-z_][A-Za-z0-9_]*)/g;

/** → caminho absoluto lexical | null (variável não resolvida, `~user`, diretório desconhecido).
 *  4º parâmetro (acréscimo): { expandir } — false para palavra sem marca expansao/til (o `$` e o `~` são literais). */
export function normalizar(caminho, dirCorrente, ctx, { expandir = true } = {}) {
  if (typeof caminho !== 'string' || caminho === '') return null;
  let p = caminho;
  if (expandir) {
    if (p === '~' || p.startsWith('~/')) p = ctx.home + p.slice(1);
    else if (p.startsWith('~')) return null;
    const valores = { HOME: ctx.home, PWD: dirCorrente, TMPDIR: ctx.tmpdir, CLAUDE_PLUGIN_ROOT: ctx.pluginRoot, CLAUDE_PROJECT_DIR: ctx.projectDir };
    let falhou = false;
    p = p.replace(RE_VAR, (_, a, b) => {
      const nome = a || b;
      const v = Object.prototype.hasOwnProperty.call(valores, nome) ? valores[nome] : null;
      if (v === null || v === undefined || v === '') { falhou = true; return ''; }
      return v;
    });
    if (falhou || p.includes('$')) return null;
  }
  if (!p.startsWith('/')) {
    if (!dirCorrente) return null;
    p = dirCorrente + '/' + p;
  }
  return semBarraFinal(resolve(p));
}

// ── `cd` (REQ-H0-8) ────────────────────────────────────────────────────────────────────────
const LIBERA_PENDENTE = new Set([';', '\n', '||', '&', null]);

function destinoDoCd(seg, dirs, ctx) {
  const args = seg.palavras.slice(seg.idxComando + 1).filter((p) => !/^-[LPe@]+$/.test(p.valor));
  if (args.length === 0) return [ctx.home];
  const a = args[0];
  if (a.valor === '-') return [null];
  const expandir = a.marcas.expansao || a.marcas.til;
  return dirs.map((d) => normalizar(a.valor, d, ctx, { expandir }));
}

const unir = (...ls) => {
  const out = [];
  for (const v of ls.flat()) if (!out.includes(v)) out.push(v);
  return out;
};

/** Acrescenta seg.dirs:(string|null)[] em cada segmento (null = diretório desconhecido). Recursivo em
 *  substituições, `bash -c`/`eval` e corpo de heredoc. 3º parâmetro (acréscimo): diretórios iniciais. */
export function anotarDiretorios(analise, ctx, dirsIniciais = [ctx.cwd]) {
  let atual = [...dirsIniciais];
  let pendente = [];
  const pilha = []; // { id, atual, pendente } salvos ao abrir subshell
  for (const seg of analise.segmentos) {
    while (pilha.length && !seg.subshells.includes(pilha[pilha.length - 1].id)) {
      const s = pilha.pop();
      atual = s.atual;
      pendente = s.pendente;
    }
    for (const id of seg.subshells) {
      if (!pilha.some((s) => s.id === id)) pilha.push({ id, atual: [...atual], pendente: [...pendente] });
    }
    seg.dirs = [...atual];
    for (const p of seg.palavras) for (const a of p.internos) anotarDiretorios(a, ctx, seg.dirs);
    for (const a of seg.internos) anotarDiretorios(a, ctx, seg.dirs);
    for (const h of seg.heredocs) if (h.corpoAnalise) anotarDiretorios(h.corpoAnalise, ctx, seg.dirs);
    for (const r of seg.redirs) if (r.alvo) for (const a of r.alvo.internos) anotarDiretorios(a, ctx, seg.dirs);

    const emPipe = seg.seguidoDePipe || seg.depoisDePipe;
    if (nomeBase(seg.comando) === 'cd' && seg.idxComando >= 0 && !emPipe && seg.conector !== '&') {
      const novos = destinoDoCd(seg, atual, ctx);
      if (seg.conector === '&&') {
        pendente = unir(pendente, atual);
        atual = unir(novos);
      } else {
        atual = unir(atual, novos);
      }
    }
    if (LIBERA_PENDENTE.has(seg.conector) && pendente.length) {
      atual = unir(atual, pendente);
      pendente = [];
    }
  }
  return analise;
}

const MENSAGEM_GIT = { commit: true, tag: true, merge: true, 'stash push': true, 'stash save': true, 'notes add': true, 'notes append': true };
const GH_TEXTO = { pr: ['create', 'edit', 'comment', 'review', 'merge'], issue: ['create', 'edit', 'comment'], release: ['create', 'edit'] };
const GH_OPCOES_TEXTO = new Set(['--title', '-t', '--body', '-b', '--subject', '--notes', '-n']);
const FILTRO = new Set(['-t', '--testNamePattern', '-g', '--grep', '--test-name-pattern']);
const FLAG_V = new Set(['-C', '--git-dir', '--work-tree', '-o', '--output', '--outputFile', '--outFile', '--outDir', '--test-reporter-destination', '-f', '--file']);
const FLAG_V_SAIDA = new Set(['-o', '--output', '--outputFile', '--outFile', '--outDir', '--test-reporter-destination']);
const GIT_GLOBAL_COM_VALOR = new Set(['-C', '-c', '--git-dir', '--work-tree', '--namespace', '--exec-path', '--config-env', '--super-prefix']);
const GIT_REF_CAMINHO = new Set(['show', 'diff', 'log', 'cat-file', 'grep']);
const FIND_ACAO_ARQUIVO = new Set(['-fprint', '-fprint0', '-fls', '-fprintf']);
const RUNNERS_X = new Set(['npx', 'bunx']);

/** Índice (em seg.palavras) do subcomando do git, pulando opções globais; -1 se não houver. */
function idxSubGit(seg) {
  const ps = seg.palavras;
  let k = seg.idxComando + 1;
  while (k < ps.length && ps[k].valor.startsWith('-')) {
    k += GIT_GLOBAL_COM_VALOR.has(ps[k].valor) ? 2 : 1;
  }
  return k < ps.length ? k : -1;
}

/** Ferramenta efetiva atrás de npx|bunx|pnpm exec|pnpm dlx|yarn dlx|yarn <bin>: { nome, idx } ou null. */
function ferramentaDoRunner(seg) {
  const ps = seg.palavras;
  const c = nomeBase(seg.comando);
  let k = seg.idxComando + 1;
  if (RUNNERS_X.has(c)) {
    while (k < ps.length && ps[k].valor.startsWith('-')) k++;
  } else if (c === 'pnpm' && ps[k] && (ps[k].valor === 'exec' || ps[k].valor === 'dlx')) k++;
  else if (c === 'yarn' && ps[k] && ps[k].valor === 'dlx') k++;
  else if (c === 'yarn' && ps[k] && !['test', 'run'].includes(ps[k].valor) && !ps[k].valor.startsWith('-')) { /* yarn <bin> */ } else return null;
  return k < ps.length ? { nome: nomeBase(ps[k].valor), idx: k } : null;
}

/** Marca o VALOR da opção em `ops` (próxima palavra, ou `--op=` / `-Xvalor` colado). */
function marcarValores(ps, de, ate, ops, alvo, { coladoCurto = false } = {}) {
  for (let k = de; k < ate; k++) {
    const v = ps[k].valor;
    if (ops.has(v)) { if (k + 1 < ate) alvo.add(k + 1); k++; continue; }
    const eq = v.indexOf('=');
    if (v.startsWith('--') && eq > 0 && ops.has(v.slice(0, eq))) { alvo.add(k); continue; }
    if (coladoCurto && /^-[A-Za-z]./.test(v) && ops.has(v.slice(0, 2))) alvo.add(k);
  }
}

/** → { puro:Set, verif:Set, findExpr:Set, saida:Set(idx de valor de flag (v) de saída), flagV:Set } */
function classificar(seg) {
  const ps = seg.palavras;
  const n = ps.length;
  const puro = new Set();
  const verif = new Set();
  const findExpr = new Set();
  const flagV = new Set();
  const saida = new Set();
  if (seg.idxComando < 0) return { puro, verif, findExpr, flagV, saida };
  const c = nomeBase(seg.comando);
  const a0 = seg.idxComando + 1;

  // texto puro
  if (c === 'echo' || c === 'printf') for (let k = a0; k < n; k++) puro.add(k);
  if (c === 'date') for (let k = a0; k < n; k++) if (ps[k].valor.startsWith('+')) puro.add(k);
  let sub = -1;
  if (c === 'git') {
    sub = idxSubGit(seg);
    if (sub >= 0) {
      const s1 = ps[sub].valor;
      const s2 = sub + 1 < n ? `${s1} ${ps[sub + 1].valor}` : s1;
      if (MENSAGEM_GIT[s1] || MENSAGEM_GIT[s2]) {
        for (let k = sub + 1; k < n; k++) {
          const v = ps[k].valor;
          if (/^-[A-Za-z]*m$/.test(v) || v === '--message') { if (k + 1 < n) puro.add(k + 1); puro.add(k); k++; continue; }
          if (v.startsWith('--message=') || /^-m./.test(v)) puro.add(k);
        }
      }
    }
  }
  if (c === 'gh' && a0 + 1 < n && (GH_TEXTO[ps[a0].valor] || []).includes(ps[a0 + 1].valor)) {
    for (let k = a0 + 2; k < n; k++) {
      const v = ps[k].valor;
      if (GH_OPCOES_TEXTO.has(v)) { if (k + 1 < n) puro.add(k + 1); k++; continue; }
      const eq = v.indexOf('=');
      if (eq > 0 && GH_OPCOES_TEXTO.has(v.slice(0, eq))) puro.add(k);
    }
  }

  // texto verificável
  const ehGitGrep = c === 'git' && sub >= 0 && ps[sub].valor === 'grep';
  if (VERIFICAVEL_CMD.has(c)) for (let k = a0; k < n; k++) verif.add(k);
  if (ehGitGrep) for (let k = sub + 1; k < n; k++) verif.add(k);
  if (c === 'git' && sub >= 0 && ps[sub].valor === 'log') {
    marcarValores(ps, sub + 1, n, new Set(['--grep', '-S', '-G']), verif, { coladoCurto: true });
    for (let k = sub + 1; k < n; k++) if (/^--(format|pretty)=/.test(ps[k].valor)) verif.add(k);
  }
  const ferr = ferramentaDoRunner(seg);
  const nomeFerr = ferr ? ferr.nome : c;
  const deFerr = ferr ? ferr.idx + 1 : a0;
  if (nomeFerr === 'jest' || nomeFerr === 'vitest') marcarValores(ps, deFerr, n, new Set(['-t', '--testNamePattern']), verif);
  if (nomeFerr === 'playwright' && ps[deFerr] && ps[deFerr].valor === 'test') marcarValores(ps, deFerr + 1, n, new Set(['-g', '--grep']), verif);
  if (nomeFerr === 'node' && ps.slice(deFerr).some((p) => p.valor === '--test')) marcarValores(ps, deFerr, n, new Set(['--test-name-pattern']), verif);
  if (['npm', 'pnpm', 'yarn'].includes(c) && a0 < n && ['test', 'run'].includes(ps[a0].valor)) {
    const ddash = ps.findIndex((p, k) => k > a0 && p.valor === '--' && p.cru === '--');
    if (ddash >= 0) marcarValores(ps, ddash + 1, n, FILTRO, verif);
    else if (c === 'yarn') marcarValores(ps, a0 + 1, n, FILTRO, verif);
  }

  // find: pontos de partida são candidatos; a expressão não (salvo arquivo de -fprint*/-fls)
  if (c === 'find') {
    let k = a0;
    while (k < n && /^-([HLPEXdsx]|O\d*)$/.test(ps[k].valor)) k++;
    if (k < n && ps[k].valor === '-D') k += 2;
    while (k < n && (ps[k].valor === '-f')) k += 2;
    while (k < n && !ps[k].valor.startsWith('-') && !['(', '!', ')', ','].includes(ps[k].valor)) k++;
    for (let j = k; j < n; j++) {
      findExpr.add(j);
      if (FIND_ACAO_ARQUIVO.has(ps[j].valor) && j + 1 < n) { flagV.add(j + 1); saida.add(j + 1); findExpr.delete(j + 1); j++; }
    }
  }

  // (v) flags com caminho, de qualquer comando (`-o` de busca é --only-matching; find usa a regra acima)
  if (c !== 'find') {
    const semO = BUSCA.has(c) || ehGitGrep;
    for (let k = a0; k < n; k++) {
      const v = ps[k].valor;
      if (FLAG_V.has(v) && !(semO && v === '-o')) {
        if (k + 1 < n && !ps[k + 1].valor.startsWith('-')) {
          flagV.add(k + 1);
          if (FLAG_V_SAIDA.has(v)) saida.add(k + 1);
        }
        k++;
        continue;
      }
      const eq = v.indexOf('=');
      if (v.startsWith('--') && eq > 0 && FLAG_V.has(v.slice(0, eq))) {
        flagV.add(k);
        if (FLAG_V_SAIDA.has(v.slice(0, eq))) saida.add(k);
      }
    }
    if (c === 'git') for (let k = a0; k < (sub < 0 ? n : sub); k++) if (ps[k].valor === '-C' && k + 1 < n) flagV.add(k + 1);
  }
  return { puro, verif, findExpr, flagV, saida };
}

/** Operandos (índices) depois do comando: palavras que não começam com `-`, e todas depois de `--`. */
function operandos(seg, de = seg.idxComando + 1) {
  const out = [];
  let fimOpcoes = false;
  for (let k = de; k < seg.palavras.length; k++) {
    const v = seg.palavras[k].valor;
    if (!fimOpcoes && v === '--' && seg.palavras[k].cru === '--') { fimOpcoes = true; continue; }
    if (fimOpcoes || !v.startsWith('-') || v === '-') out.push(k);
  }
  return out;
}

/** → boolean: a palavra idx está em posição de destino (lista de REQ-H4-3). */
export function posicaoDeDestino(seg, idxPalavra) {
  if (seg.idxComando < 0 || idxPalavra <= seg.idxComando) return false;
  const ps = seg.palavras;
  const c = nomeBase(seg.comando);
  const ops = operandos(seg);
  const opcoes = ps.slice(seg.idxComando + 1).map((p) => p.valor).filter((v) => v.startsWith('-'));
  switch (c) {
    case 'cp': case 'install': case 'ln':
      return ops.length >= 2 && idxPalavra === ops[ops.length - 1];
    case 'rsync':
      if (opcoes.includes('--remove-source-files')) return ops.includes(idxPalavra);
      return ops.length >= 2 && idxPalavra === ops[ops.length - 1];
    case 'mv': case 'rm': case 'chmod': case 'chown': case 'chflags': case 'truncate': case 'touch': case 'tee':
      return ops.includes(idxPalavra);
    case 'sed':
      return opcoes.some((o) => o.startsWith('-i') || o.startsWith('--in-place')) && ops.includes(idxPalavra);
    case 'perl':
      return opcoes.some((o) => /^-[A-Za-z]*i/.test(o)) && ops.includes(idxPalavra);
    case 'dd':
      return ps[idxPalavra].valor.startsWith('of=');
    case 'git': {
      const sub = idxSubGit(seg);
      if (sub < 0 || !['checkout', 'restore'].includes(ps[sub].valor)) return false;
      return operandos(seg, sub + 1).includes(idxPalavra);
    }
    default:
      return false;
  }
}

/** URLs (<esquema>://…) não são candidatos de caminho. */
export function ehUrl(valor) {
  return /^[A-Za-z][A-Za-z0-9+.-]*:\/\//.test(String(valor));
}

/** @typedef {{ valor:string, abs:(string|null)[], dirs:(string|null)[], palavra:import('./palavras.mjs').Palavra, destino:boolean,
 *   fonte:'i'|'ii'|'iii'|'iv'|'v', classe:'caminho'|'verificavel' }} Candidato   // abs: um por diretório corrente possível (dirs) */
/** → Candidato[] do segmento (exclui texto puro e expressão de find; inclui texto verificável marcado). Usa seg.dirs (anotarDiretorios). */
export function candidatos(seg, ctx) {
  const dirs = seg.dirs ?? [ctx.cwd];
  const ps = seg.palavras;
  const { puro, verif, findExpr, flagV, saida } = classificar(seg);
  const c = nomeBase(seg.comando);
  const gitSub = c === 'git' ? idxSubGit(seg) : -1;
  const refCaminho = gitSub >= 0 && GIT_REF_CAMINHO.has(ps[gitSub].valor);
  const out = [];

  const add = (valor, palavra, fonte, classe, destino) => {
    const fila = [[valor, fonte]];
    const vistos = new Set();
    while (fila.length) {
      const [v, f] = fila.shift();
      if (!v || vistos.has(v) || ehUrl(v)) continue;
      vistos.add(v);
      const expandir = palavra.marcas.expansao || palavra.marcas.til;
      out.push({ valor: v, abs: dirs.map((d) => normalizar(v, d, ctx, { expandir })), dirs: [...dirs], palavra, destino, fonte: f, classe });
      const eq = v.indexOf('=');
      if (eq >= 0) fila.push([v.slice(eq + 1), 'iii']);
      if (v.startsWith('@')) fila.push([v.slice(1), 'iii']);
    }
  };

  for (let k = 0; k < ps.length; k++) {
    if (puro.has(k) || findExpr.has(k)) continue;
    const p = ps[k];
    const v = p.valor;
    const destino = posicaoDeDestino(seg, k) || saida.has(k);
    const classe = verif.has(k) && !flagV.has(k) && !destino ? 'verificavel' : 'caminho';
    if (v.startsWith('-')) {
      const m = /^--?[^=]+=([\s\S]*)$/.exec(v);
      if (m) add(m[1], p, flagV.has(k) ? 'v' : 'ii', classe, destino);
      continue;
    }
    add(v, p, flagV.has(k) ? 'v' : 'i', classe, destino);
    if (refCaminho && k > gitSub && v.includes(':') && !ehUrl(v)) add(v.slice(v.lastIndexOf(':') + 1), p, 'iv', 'caminho', false);
  }
  for (const r of seg.redirs) {
    if (r.alvo && r.direcao !== 'dup') add(r.alvo.valor, r.alvo, 'v', 'caminho', r.direcao === 'saida');
  }
  return out;
}

/** Caminho físico: realpath do ancestral mais fundo que existe + o resto. */
function fisico(abs) {
  let atual = abs;
  const resto = [];
  for (;;) {
    try { return semBarraFinal([realpathSync(atual), ...resto.reverse()].join('/').replace(/\/+/g, '/')); } catch { /* sobe */ }
    const pai = dirname(atual);
    if (pai === atual) return abs;
    resto.push(basename(atual));
    atual = pai;
  }
}
/** Formas de um caminho: lexical e física (macOS: /var → /private/var; symlink dentro do repo). */
function formas(abs) {
  const f = fisico(abs);
  return f === abs ? [abs] : [abs, f];
}
const sob = (a, raiz) => a === raiz || a.startsWith(raiz.endsWith(sep) ? raiz : raiz + sep);
const sobAlguma = (a, raizesLista) => raizesLista.some((r) => sob(a, r));
const comFormas = (lista) => [...new Set(lista.filter(Boolean).flatMap(formas))];
const DISPOSITIVOS = new Set(['/dev/null', '/dev/stdout', '/dev/stderr']);

/** Texto verificável volta a candidato se existe e é segredo, ou (S) fora do escopo de leitura.
 *  4º parâmetro (acréscimo): expandir(palavra, dir) → string[] — expansão de glob/chaves (segredos.expandirGlob, T5). */
export function verificavelViraCandidato(cand, ctx, ehSegredo, expandir = null) {
  const abss = [...cand.abs];
  if (expandir && cand.valor === cand.palavra.valor && (cand.palavra.marcas.glob || cand.palavra.marcas.chaves)) {
    for (const d of cand.dirs ?? []) if (d !== null) abss.push(...expandir(cand.palavra, d));
  }
  for (const abs of abss) {
    if (abs === null || !existsSync(abs)) continue;
    if (ehSegredo(abs, ctx)) return true;
    if (ctx.s && !noEscopoLeitura(abs, ctx)) return true;
  }
  return false;
}

/** REQ-H4-1 (acréscimo ao contrato, consumido pela T10): alvo de configuração de guarda. `diretorios` inclui os
 *  diretórios-alvo (só para REQ-H4-3). */
export function ehAlvoConfig(abs, ctx, { diretorios = false } = {}) {
  if (abs === null) return false;
  const raizesLista = [ctx.raizWT, ctx.raizPrincipal, ctx.projectDir].filter(Boolean);
  const exatos = [`${ctx.home}/.claude/settings.json`, `${ctx.home}/.claude/settings.local.json`, `${ctx.home}/.claude.json`];
  const subarvores = [`${ctx.home}/.claude/hooks`, `${ctx.home}/.claude/plugins`];
  const dirsAlvo = [`${ctx.home}/.claude`, `${ctx.home}/.claude/hooks`, `${ctx.home}/.claude/plugins`];
  for (const r of raizesLista) {
    exatos.push(`${r}/.claude/settings.json`, `${r}/.claude/settings.local.json`, `${r}/.mcp.json`, `${r}/harness.config.json`);
    subarvores.push(`${r}/.claude/hooks`);
    dirsAlvo.push(`${r}/.claude`, `${r}/.claude/hooks`);
  }
  const ex = comFormas(exatos);
  const sa = comFormas(subarvores);
  const da = comFormas(dirsAlvo);
  return formas(abs).some((f) => ex.includes(f) || sa.some((s) => f !== s && sob(f, s)) || (diretorios && da.includes(f)));
}

/** Pertença a escopo decide pela forma FÍSICA do caminho contra a forma física das raízes: `/var/folders/…` e
 *  `/private/var/folders/…` decidem igual, e symlink de dentro do worktree para fora fica fora (Review Focus 3). */
const fisicoSob = (abs, raizesLista) => sobAlguma(fisico(abs), raizesLista.filter(Boolean).map(fisico));

/** r23 (ruling R4): fora de git, RAIZ_WT (= cwd) igual a $HOME, ancestral de $HOME ou `/` não é gravável por S. */
function raizWTSemEscrita(ctx) {
  if (!ctx.semGit || !ctx.raizWT) return false;
  const wt = fisico(ctx.raizWT);
  return wt === '/' || (Boolean(ctx.home) && sob(fisico(ctx.home), wt));
}

/** REQ-H0-5: escopo de escrita de S (r23: exceção de $HOME/ancestral/`/` fora de git). */
export function noEscopoEscrita(abs, ctx) {
  if (abs === null || abs === undefined) return false;
  if (DISPOSITIVOS.has(abs)) return true;
  const wt = raizWTSemEscrita(ctx) ? null : ctx.raizWT;
  if (!fisicoSob(abs, [wt, ctx.tmpdir, '/tmp', '/private/tmp'])) return false;
  const proibidas = comFormas([ctx.raizWT, ctx.raizPrincipal, ctx.projectDir].filter(Boolean).flatMap((r) => [`${r}/.git`, `${r}/.husky`]));
  if (formas(abs).some((f) => sobAlguma(f, proibidas))) return false;
  return !ehAlvoConfig(abs, ctx, { diretorios: true });
}

/** REQ-H0-5: escopo de leitura de S = escrita + RAIZ_PRINCIPAL + ~/.claude/plugins/. */
export function noEscopoLeitura(abs, ctx) {
  if (abs === null || abs === undefined) return false;
  if (DISPOSITIVOS.has(abs)) return true;
  return fisicoSob(abs, [ctx.raizWT, ctx.tmpdir, '/tmp', '/private/tmp', ctx.raizPrincipal, `${ctx.home}/.claude/plugins`]);
}

  gabarito_read_payload

  fi
}

# Diretório desta biblioteca (para ler lib/medicoes.mjs). BASH_SOURCE existe no bash 3.2.
GABARITO_HOOKS_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
GABARITO_SUFIXO_S='subagente não usa escape hatch nem contorna bloqueio — devolva ao orquestrador o comando e o motivo'

# Lê um booleano de lib/medicoes.mjs (formato fixo: `<chave>: true|false,` numa linha), em bash puro — sem
# sed/grep: roda em todo comando Bash (R3, R2 de S). Arquivo ausente ou chave ilegível → o valor conservador
# passado como 2º argumento.
gabarito_medicao() {
  local arq="$GABARITO_HOOKS_DIR/lib/medicoes.mjs" linha resto v=""
  if [ -r "$arq" ]; then
    while IFS= read -r linha || [ -n "$linha" ]; do
      linha="${linha#"${linha%%[![:space:]]*}"}"
      case "$linha" in
        "$1:"*)
          resto="${linha#"$1:"}"; resto="${resto#"${resto%%[![:space:]]*}"}"
          case "$resto" in true,*) v=true ;; false,*) v=false ;; esac
          break ;;
      esac
    done < "$arq"
  fi
  printf '%s' "${v:-$2}"
}

# REQ-H0-3: S = agent_id não vazio. Fallback (só se M-B = não, ou seja, medicoes.agentIdEmForkEWorkflow false):
# cwd do PAYLOAD sob */.claude/worktrees/agent-* ⇒ S, e GABARITO_S_PELO_CWD=1. Nunca usa o pwd do hook.
gabarito_eh_subagente() {

}

# Escapa uma string para dentro de um literal JSON: \ " e controles (tab, newline, etc.).
gabarito_json_escape() {
  printf '%s' "$1" | LC_ALL=C awk '
    BEGIN { ORS = "" }
    {
      if (NR > 1) printf "\\n"
      s = $0
      gsub(/\\/, "\\\\", s); gsub(/"/, "\\\"", s); gsub(/\t/, "\\t", s); gsub(/\r/, "\\r", s)
      gsub(/[[:cntrl:]]/, " ", s)
      printf "%s", s
    }'
}

# Escape hatch nominal e grepável. Assinatura: gabarito_escape_hatch <ROTULO> [<VAR>]
#   gabarito_escape_hatch "R2 · rm recursivo" GABARITO_ALLOW_DESTRUCTIVE
#   gabarito_escape_hatch "R20 · cabeçalho" GABARITO_ALLOW_VERSIONING
# <VAR> é o nome da variável que libera ESTE hook. Compatibilidade medida (README "Escape hatch"):
# GABARITO_ALLOW_DESTRUCTIVE e GABARITO_ALLOW_PRODUCTION aceitam uma pela outra — SÓ entre essas duas.
# Qualquer outra variável (ex.: GABARITO_ALLOW_VERSIONING) libera só o seu hook: hatches não cruzam.
# Sem <VAR> (chamada antiga com um argumento) vale o par DESTRUCTIVE/PRODUCTION.
# Vale (1) no ambiente do processo do Claude Code, ou (2) como PREFIXO do próprio comando —
# só no INÍCIO do comando, para que comentário ou `echo` no meio não libere:
#   GABARITO_ALLOW_DESTRUCTIVE='expurgo de build autorizado por gabriel 2026-09-05' <comando>
# O motivo precisa ter ≥ 8 caracteres e ≥ 2 palavras — "lol" não é motivo. Vazio NÃO libera.
# Devolve 0 (liberado) e imprime o aviso; devolve 1 se não há liberação.
gabarito_escape_hatch() {
  local rotulo="$1"
  local vars="${2-}"
  # REQ-H1-1: subagente nunca usa hatch — nem do ambiente, nem do prefixo do comando.
  if gabarito_eh_subagente; then
    echo "gabarito-mestre: escape hatch ignorado: chamada de subagente (agent_type=${GABARITO_AGENT_TYPE:-?}) ($rotulo)" >&2
    return 1
  fi
  case "$vars" in
    ""|GABARITO_ALLOW_DESTRUCTIVE|GABARITO_ALLOW_PRODUCTION) vars="GABARITO_ALLOW_DESTRUCTIVE GABARITO_ALLOW_PRODUCTION" ;;
  esac
  local motivo="" v origem="env"
  for v in $vars; do
    case "$v" in
      *[!A-Z0-9_]*|"") continue ;;   # só identificador entra no eval
    esac
    [ -z "$motivo" ] && eval "motivo=\${$v-}"
  done
  if [ -z "$motivo" ]; then
    local alt
    alt=$(printf '%s' "$vars" | tr ' ' '|')
    motivo=$(printf '%s' "$GABARITO_CMD" | head -n1 | sed -nE "s/^[[:space:]]*(${alt})=(\"([^\"]*)\"|'([^']*)'|([^[:space:]]*)).*/\3\4\5/p")
    origem="inline"
  fi
  motivo=$(printf '%s' "$motivo" | sed -E 's/^[[:space:]]+//; s/[[:space:]]+$//')
  [ -z "$motivo" ] && return 1
  local palavras
  palavras=$(printf '%s' "$motivo" | wc -w | tr -d ' ')
  if [ "${#motivo}" -lt 8 ] || [ "$palavras" -lt 2 ]; then
    echo "gabarito-mestre: escape hatch IGNORADO ($rotulo) — motivo curto demais (mínimo 8 caracteres e 2 palavras): '$motivo'" >&2
    return 1
  fi
  local esc esc_rotulo esc_origem
  esc=$(gabarito_json_escape "$motivo")
  esc_rotulo=$(gabarito_json_escape "$rotulo")
  esc_origem=$(gabarito_json_escape "$origem")
  echo "gabarito-mestre: ESCAPE HATCH usado ($rotulo, via $origem) — motivo: $motivo" >&2
  printf '{"systemMessage":"⚠ gabarito-mestre: escape hatch usado (%s, via %s). Motivo declarado: %s"}\n' "$esc_rotulo" "$esc_origem" "$esc"
  return 0
}

# REQ-H0-4 (M-C): raiz do checkout PRINCIPAL. gabarito_raiz_principal [dir] — dir padrão: cwd do payload se for
# diretório, senão o pwd. `--git-common-dir` termina em `/.git` ⇒ o pai; senão (ou M-C = não) a 1ª entrada de
# `git worktree list --porcelain`; fora de git, gabarito_repo_root. Nunca falha, nunca imprime erro.
gabarito_raiz_principal() {
  local d="${1-}" c=""
  [ -z "$d" ] && { [ -n "${GABARITO_CWD-}" ] && [ -d "${GABARITO_CWD-}" ] && d="$GABARITO_CWD" || d=$(pwd -P); }
  if [ "$(gabarito_medicao worktreeUsaGitCommonDir true)" = "true" ]; then
    c=$(git -C "$d" rev-parse --path-format=absolute --git-common-dir 2>/dev/null)
    case "$c" in */.git) printf '%s' "${c%/.git}"; return 0 ;; esac
  fi
  c=$(git -C "$d" worktree list --porcelain 2>/dev/null | sed -n '1s/^worktree //p')
  if [ -n "$c" ]; then printf '%s' "$c"; else (cd "$d" 2>/dev/null && gabarito_repo_root); fi
}

# Raiz do repositório: `git rev-parse --show-toplevel` (sessão aberta em subpasta de monorepo resolve
# para a raiz); sem git ou fora de repo, o diretório atual. Nunca falha, nunca imprime erro.
gabarito_repo_root() {
  local r
  r=$(git rev-parse --show-toplevel 2>/dev/null)
  if [ -n "$r" ]; then printf '%s' "$r"; else printf '%s' "$(pwd -P)"; fi
}

# Lê um valor de `<raiz>/harness.config.json` por caminho pontuado: gabarito_config_get versionamento.resolvidoEm [raiz]
# Saída: escalar cru (string/número/true/false); array → um elemento por linha; objeto → JSON compacto;
# ausente, null, arquivo ausente ou JSON inválido → vazio (quem chama decide o fail-open).
# Parser: jq → node → python3, como gabarito_read_command. Sem parser: vazio.
gabarito_config_get() {
  local caminho="$1" raiz="${2-}" arq
  [ -z "$raiz" ] && raiz=$(gabarito_repo_root)
  arq="$raiz/harness.config.json"
  [ -f "$arq" ] || return 0
  if command -v jq >/dev/null 2>&1; then
    jq -r --arg p "$caminho" 'getpath($p | split(".")) | if . == null then empty elif type == "array" then .[] elif type == "object" then tojson else tostring end' "$arq" 2>/dev/null
  elif command -v node >/dev/null 2>&1; then
    node -e 'const [f,p]=process.argv.slice(1);let j;try{j=JSON.parse(require("fs").readFileSync(f,"utf8"))}catch(e){process.exit(0)}let v=j;for(const k of p.split(".")){if(v==null||typeof v!=="object"){v=undefined;break}v=v[k]}if(v==null)process.exit(0);if(Array.isArray(v))process.stdout.write(v.map(String).join("\n")+"\n");else if(typeof v==="object")process.stdout.write(JSON.stringify(v)+"\n");else process.stdout.write(String(v)+"\n")' "$arq" "$caminho" 2>/dev/null
  elif command -v python3 >/dev/null 2>&1; then
    python3 -c 'import sys,json
f,p=sys.argv[1],sys.argv[2]
try: j=json.load(open(f))
except Exception: sys.exit(0)
v=j
for k in p.split("."):
  v=v.get(k) if isinstance(v,dict) else None
  if v is None: sys.exit(0)
if isinstance(v,bool): print("true" if v else "false")
elif isinstance(v,list): print("\n".join(str(x) for x in v))
elif isinstance(v,dict): print(json.dumps(v))
else: print(v)' "$arq" "$caminho" 2>/dev/null
  fi
  return 0
}

# Traduz um regex vindo do JSON (estilo JavaScript: \d, \w) para ERE do grep -E do sistema (BSD e GNU).
gabarito_ere() {
  printf '%s' "$1" | sed -E 's/\\d/[0-9]/g; s/\\w/[A-Za-z0-9_]/g'
}

# Bloqueia: JSON no stdout (lido pelo Claude Code mesmo com exit 2) + motivo no stderr + exit 2.
# REQ-H1-2: negação para S termina com GABARITO_SUFIXO_S (e diz quando S foi inferido pelo cwd).
gabarito_deny() {
  local reason="$1"
  local esc
  if gabarito_eh_subagente; then
    [ -n "$GABARITO_S_PELO_CWD" ] && reason="$reason — tratado como subagente pelo cwd"
    reason="$reason — $GABARITO_SUFIXO_S"
  fi
  esc=$(gabarito_json_escape "$reason")
  printf '{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"%s"}}\n' "$esc"
  echo "$reason" >&2
  exit 2
}

# ── Normalização do texto varrido: MENÇÃO ≠ EXECUÇÃO ────────────────────────────────────
# 1. Remove o corpo de heredocs que só ESCREVEM ARQUIVO (`cat > x <<'EOF'`, `cat >> x <<'EOF'`,
#    `tee x <<'EOF'`) — anotação em progress.md que cita `rm -rf` não é `rm -rf` (falso positivo real,
#    medido em 7.037 comandos). SÓ quando o terminador é CITADO ('EOF'/"EOF"): em heredoc sem aspas
#    o bash expande `$(…)`, `` `…` `` e `${…}` na hora da escrita, então essas linhas são mantidas.
#    Qualquer outro heredoc (psql <<SQL, bash <<EOF, python3 - <<PY, `cat <<EOF | bash`) é mantido.
# 2. Remove segmentos de comando que só LEEM ou REGISTRAM texto: grep/rg/ag, git grep/log/commit -m,
#    sed. `grep "DROP TABLE"` e `git commit -m "fix: prod.example.com"` são menção, não acesso.
#    O corte é no próximo `|`, `;` ou `&` — o que vem depois (`| xargs rm -rf`) continua varrido.
# LIMITE DECLARADO: script escrito por heredoc/Write e executado no comando seguinte é invisível a
# este grep — para isso existem as guardas de runtime (G3/G7) e o review adversarial.
# Só a etapa 1 (heredocs de escrita), sem remover grep/sed/commit: é o que guard-versioning.sh usa,
# porque lá `git commit -m` É o objeto inspecionado — mas anotação em heredoc citando um commit não é commit.
gabarito_strip_write_heredocs() {
  awk '
    BEGIN { skip = 0; quoted = 0 }
    skip == 1 {
      t = $0; sub(/^\t+/, "", t)
      if (t == term) { skip = 0; next }
      if (quoted == 0 && ($0 ~ /\$\(/ || $0 ~ /`/ || $0 ~ /\$\{/)) { print; next }
      next
    }
    {
      if ($0 ~ /^[[:space:]]*(cat[[:space:]]*>>?[[:space:]]*[^|;&<]*<<-?[[:space:]]*["'"'"']?[A-Za-z_][A-Za-z0-9_]*["'"'"']?[[:space:]]*$|cat[[:space:]]+<<-?[[:space:]]*["'"'"']?[A-Za-z_][A-Za-z0-9_]*["'"'"']?[[:space:]]*>>?[[:space:]]*[^|;&<]*$|tee([[:space:]]+-a)?[[:space:]]+[^|;&<]*<<-?[[:space:]]*["'"'"']?[A-Za-z_][A-Za-z0-9_]*["'"'"']?[[:space:]]*$)/) {
        t = $0; sub(/^.*<<-?[[:space:]]*/, "", t); sub(/[[:space:]]*>.*$/, "", t)
        quoted = (t ~ /^["'"'"']/) ? 1 : 0
        gsub(/["'"'"']/, "", t); term = t; skip = 1; print; next
      }
      print
    }'
}
