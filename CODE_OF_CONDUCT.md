# Código de Conduta

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/),
versão 2.1, em português.

**Resumo do que esperamos:** respeito, crítica ao trabalho e não à pessoa, evidência antes de opinião — a mesma
disciplina que o harness pede do código. Sem assédio, sem discriminação, sem ataque pessoal, em nenhum canal do projeto.

**Aplicação:** relatos para o mantenedor pelo e-mail no perfil de [@gabrielnfc](https://github.com/gabrielnfc) ou
por issue privada (GitHub → Security → "Report a vulnerability" também serve para conduta, se preferir sigilo).
O mantenedor responde em até 7 dias. Consequências seguem a escala do Covenant: correção → advertência →
suspensão temporária → banimento.

Texto integral: https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/
